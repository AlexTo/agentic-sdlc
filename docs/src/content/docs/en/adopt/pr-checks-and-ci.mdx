**You'll end with:** a **PR Checks** workflow whose failure feeds the CI loop, a **UI Screenshots**
check, and **CI** on `main`.

<Steps>

1. **Copy four workflows** from this repository's `.github/workflows/`:

   | File | What it does |
   | --- | --- |
   | `pr-checks.yml` | Lint, test and build what the PR affects; `Tasks format`; `Invariant coverage`; sharded e2e gathered into one `E2E tests` check; the `E2E screenshots` comment |
   | `ui-screenshots.yml` | The screenshots rule, as its own workflow, so adding or removing the `no-ui-screenshots` label re-runs only this check. Discava runs it as a PR Checks job instead. Either works |
   | `ci.yml` | The same checks on every push to `main`, Trivy, the Playwright cache, and this docs site's deploy |
   | `cache-cleanup.yml` | Deletes a PR's caches when it closes |

   Keep `pr-checks.yml`'s `name: PR Checks` exactly: Agent CI Status listens for a workflow by
   that name.

2. **Point them at your projects.** Search the copied files for `@agentic-sdlc/` and change the
   scope. Then, in `pr-checks.yml`:

   | Job | Change |
   | --- | --- |
   | `invariant-coverage` | The `paths` of code that could write your table, the same as `WRITER_PACKAGES` in step 5. Or delete the job if you don't check invariants yet |
   | `e2e` | The shard count in `matrix.shard`, to suit your suite. A shard costs about two minutes before its first test, so stop adding them once each one's tests take about that long |
   | `e2e-screenshots` | Nothing, once [step 8](../local-stack-and-e2e/) is done |

   In `ci.yml`, delete the `deploy_docs` job and its `pages: write` permission unless you publish
   a docs site from `docs/`.

3. **Keep what keeps the agent fast.** The `Check for mutations` step in `ci.yml` (`git diff
   --exit-code` after the build) catches generated files the agent forgot to commit. The
   `playwright-cache` job saves Chromium from `main`, since PR runs can only restore caches saved
   there. The `build` job saves Nx's task cache from `main`, so a PR's first run replays what
   `main` already built, and the agent waits less on every fix-up round. Each `checks` leg in PR
   Checks keeps its own cache the same way, except `lint`, which only restores. `init-monorepo`
   caps the cache at 1 GB, and Cache Cleanup frees a closed PR's share of the repository's 10 GB.
   See [Keeping it fast](../../discava/pr-checks/#keeping-it-fast) for what this saved Discava.

</Steps>

Every action is pinned to a commit SHA, and the `dependabot.yml` you copied in step 1 keeps the
pins current.

## Check it worked

Open a throwaway PR that breaks one `tasks.md` line, for example by indenting a task. The
**Tasks format** check fails with an annotation on that line:

```text
A task must be written "- [ ] T<3 digits> <description>", starting in the first column
```

Open another that changes a UI file without touching a scenario. **UI Screenshots** fails:

```text
This pull request changes UI source (…) but no e2e scenario gained a `screenshot(page, 'name')` call.
```

<Aside type="note">
`codecov/codecov-action` in the copied files needs a `CODECOV_TOKEN` secret. Remove the step if
you don't use Codecov.
</Aside>
