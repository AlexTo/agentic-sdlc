**You'll end with:** a pnpm workspace with Nx, Biome, Conventional Commits enforced on every
commit, and a secret check before every commit.

The glue doesn't need Nx. But `nx affected` is what keeps PR checks fast enough for an agent to
iterate on, and every glue script runs as an Nx target. If you use another monorepo tool, keep the
idea: run only what the PR affects, and expose every script as a named task.

<Steps>

1. **Create the workspace**, if you don't have one. Discava and this repository were both created
   with the Nx Plugin for AWS:

   ```bash
   pnpm create @aws/nx-workspace your-project --iac=cdk --no-interactive
   ```

   An existing Nx workspace works too. Pin pnpm in the root `package.json` with `packageManager`,
   so CI and the agent use the same version.

2. **Copy these files** from this repository to the same paths in yours:

   <FileTree>
   - commitlint.config.js Conventional Commits
   - lint-staged.config.js Biome on staged files
   - .husky/
     - commit-msg runs commitlint
     - pre-commit git-secrets, then lint-staged, and fails if Biome changed anything, so the agent restages and commits again
     - prepare-commit-msg Commitizen, for people who commit interactively. It skips itself for `git commit -m`, which is how agents commit
   - .git-secrets/ the git-secrets script the pre-commit hook runs
   - .gitallowed patterns git-secrets lets through
   - .github/
     - actions/init-monorepo/ shared CI setup
     - actions/changed-paths/ "did this PR change any of these paths?", for skipping jobs
     - actions/playwright-setup/ Chromium for Playwright, cached per version
     - dependabot.yml keeps the pinned actions and dependencies current
   </FileTree>

   Leave `.husky/pre-push` until [step 8](../local-stack-and-e2e/): it checks the invariant map.
   `init-monorepo` installs pnpm (with three tries, because a registry timeout would otherwise
   cost the agent a fix-up attempt), Node 24 and optionally uv, restores the pnpm and Nx caches,
   installs dependencies, and sets `NX_BASE`/`NX_HEAD` for `nx affected`.

3. **Copy the root scripts and dev dependencies** from this repository's `package.json`: the
   `scripts` block (which `AGENTS.md`, CI and the agent call), and from `devDependencies`,
   `@commitlint/config-conventional`, `commitlint`, `commitizen`, `husky` and `lint-staged`. Then:

   ```bash
   pnpm install
   ```

   Its `prepare` script installs the hooks.

4. **Change the package scope** in `.github/actions/playwright-setup/action.yml`
   (`@agentic-sdlc/e2e`) to your e2e project's name.

</Steps>

## Check it worked

```bash
git commit --allow-empty -m "not conventional"
```

```text
⧗   input: not conventional
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

Then `git commit --allow-empty -m "chore: check hooks"` succeeds.

<Aside type="note">
The issue titles the glue writes are Conventional Commit headers, and the agent reuses them for
its commits and pull requests. That is why commitlint comes first.
</Aside>
