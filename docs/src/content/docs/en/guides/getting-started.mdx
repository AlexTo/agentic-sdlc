Welcome to **docs**! This site is built with [Astro](https://astro.build/) and the
[Starlight](https://starlight.astro.build/) documentation theme.

## Run locally

```bash
pnpm nx start @agentic-sdlc/docs
```

## Build for production

```bash
pnpm nx build @agentic-sdlc/docs
```

## Adding a locale

Add an entry to the `locales` block in `astro.config.mjs` and create a matching
directory under `src/content/docs/<locale>/`. Starlight will pick up the new locale
automatically.

## Locale-aware links

Use the generated `Link` component whenever you want to link to another page
**inside** your docs — it automatically resolves the current locale, so a single
source of truth produces the right URL in every language:

```mdx
import Link from '@components/link.astro';

<Link path="guides/getting-started">Read the getting-started guide</Link>
```

Here is the component in action: <Link path="guides/getting-started">back to this page</Link>.

For regular external links, just use ordinary Markdown `[label](url)`.

## Using snippets

Snippets are reusable fragments of MDX stored in `src/content/docs/<locale>/snippets/`.
Include one in any page with the `Snippet` component:

```mdx
import Snippet from '@components/snippet.astro';

<Snippet name="example" />
```

## The sample app

This repo includes a small notes app, scaffolded with the Nx Plugin for AWS generators, to
give the lifecycle something real to act on:

| Project | Generator | Purpose |
| --- | --- | --- |
| `packages/notes-table` | `ts#dynamodb` | ElectroDB `note` entity, local DynamoDB for dev |
| `packages/notes-api` | `ts#trpc-api` | tRPC procedures: list, create, update, delete notes |
| `packages/notes-website` | `ts#react-website` | React + Vite + TanStack Router + shadcn/ui |

```bash
pnpm install
pnpm dev   # DynamoDB local (Docker), API and website
```

No infrastructure (CDK) is generated; the app runs locally only.
