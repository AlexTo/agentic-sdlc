This repository illustrates the **Agentic SDLC** adopted in
[Discava](https://github.com/AlexTo/discava), a serverless, AWS-native Learning
Management System built with AI agents from the start.

It documents the practices, not the product: how work is specified, handed to agents,
verified and shipped.

## The loop at a glance

```d2
direction: right
spec: Spec\n(spec, plan, tasks)
review: Human review
issue: Implementation issue
agent: Agent opens PR
ci: CI checks
merge: Merge to main
deploy: Deploy

spec -> review: spec PR
review -> issue: merged + labelled spec-ready
issue -> agent
agent -> ci
ci -> agent: failure (max 3 retries)
ci -> merge: pass + human review
merge -> issue: next task
merge -> deploy
```
