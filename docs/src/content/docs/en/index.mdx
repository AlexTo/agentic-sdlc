  <Card title="Spec first" icon="pencil">

  </Card>
  <Card title="Issue to pull request" icon="rocket">

  </Card>
  <Card title="Feedback without you" icon="approve-check">
    A red CI run or a "changes requested" review sends the agent back to the same PR, at most three times.
  </Card>
  <Card title="Two human decisions" icon="information">
    People approve the spec and approve the result. Everything in between runs on its own.
  </Card>
