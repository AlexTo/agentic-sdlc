| Workflow | File | Trigger | Permissions | Checks out |
| --- | --- | --- | --- | --- |
| PR Checks | `pr-checks.yml` | `pull_request` to `main` | `contents: read`, plus `pull-requests: write` for the screenshots comment job | The PR, except the screenshots comment job: the default branch |
| UI Screenshots | `ui-screenshots.yml` | `pull_request` to `main`, including `labeled`/`unlabeled` | `contents: read`, `pull-requests: read` | The default branch (reads the diff from the API) |
| CI | `ci.yml` | `push` to `main`, `workflow_dispatch` | `contents: read`, `pages: write`, `id-token: write` | `main` |
| Agent Issues | `agent-issues.yml` | `pull_request: [closed, labeled]` to `main`, `workflow_dispatch(spec_folder)` | `contents: read`, `issues: write`, `pull-requests: write` | The merge commit |
| Archive Specs | `archive-specs.yml` | `push` to `main` changing `specs/*/tasks.md`, `workflow_dispatch` | `contents: write`, `issues: read`, `pull-requests: write` | `main` |
| Agent CI Status | `agent-ci.yml` | `workflow_run` of PR Checks, `completed` | `contents: read`, `actions: read`, `statuses: write`, `issues: write`, `pull-requests: write` | The default branch (through Agent Status) |
| Agent Review Status | `agent-review.yml` | `pull_request_review: submitted` | `contents: read`, `statuses: write`, `issues: write`, `pull-requests: write` | The default branch (through Agent Status) |
| Agent Status | `agent-status.yml` | `workflow_call` from the two above, with the Nx target to run | The caller's | The default branch |
| Cache Cleanup | `cache-cleanup.yml` | `pull_request: closed` | `actions: write` | Nothing (passes the PR number to `gh`) |
| Deploy | `deploy.yml` | `workflow_run` of CI on `main` (only when `AUTO_DEPLOY_STAGE` is set), `workflow_dispatch(stage)` | `contents: read`, `id-token: write` | The commit CI verified |
| Post-merge Verify | `post-merge-verify.yml` | `workflow_run` of Deploy, `completed`, `workflow_dispatch(pr_number)` | `contents: read`, `actions: read`, `issues: write`, `pull-requests: write` | The default branch |

## Job names to require in branch protection

| Check | From |
| --- | --- |
| `Checks (lint)`, `Checks (test)`, `Checks (build)` | PR Checks |
| `Tasks format` | PR Checks |
| `Invariant coverage` | PR Checks |
| `E2E tests` | PR Checks (gathers the shards) |
| `UI Screenshots` | UI Screenshots |

## Concurrency groups

| Workflow | Group | Cancel in progress |
| --- | --- | --- |
| PR Checks | `pr-checks-<ref>` | yes: a new push makes the old run pointless |
| Agent Issues | `agent-issues-<PR number or folder>` | no |
| Archive Specs | `archive-specs` | no: one run at a time, so two never open the same PR |
| Agent CI Status | `agent-ci-<head branch>` | no |
| Agent Review Status | `agent-review-<PR number>` | no |
| Deploy | `deploy-<stage>` | no |
| Post-merge Verify | `post-merge-verify` | no: one run at a time, so two deploys close together never open two issues for one PR |

The agent workflows never cancel. Each run must count its attempt or open its issue exactly once,
and per-PR groups mean unrelated PRs never wait on each other.

## Nx targets they run

All in `@your-scope/tooling-agent`:

| Target | Entry point | Env it reads |
| --- | --- | --- |
| `agent-issue` | `src/agent-issues/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_NAME`, `GITHUB_EVENT_PATH`, `SPEC_FOLDER`, `DRY_RUN` |
| `archive-specs` | `src/agent-issues/archive-main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_WORKSPACE`, `BASE_BRANCH`, `DRY_RUN` |
| `agent-ci-status` | `src/agent-ci/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_PATH`, `DRY_RUN` |
| `agent-review-status` | `src/agent-review/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_PATH`, `AGENT_APP_LOGIN`, `DRY_RUN` |
| `validate-tasks` | `src/agent-issues/validate-main.ts` | `GITHUB_WORKSPACE`, `GITHUB_ACTIONS` (for annotations) |
| `ui-screenshots` | `src/ui-screenshots/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_PATH` |
| `screenshots-comment` | `src/ui-screenshots/comment-main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_STEP_SUMMARY`, `PR`, `SHA`, `RUN_URL`, `SCREENSHOTS_DIR` |
| `invariant-coverage` | `src/invariant-coverage/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_PATH`, `BASE_REF` |
| `entity-writers` | `src/invariant-coverage/write.ts` | Nothing. Run by the pre-push hook, or by hand |
| `post-merge-test` | `src/post-merge-test/main.ts` | `GH_TOKEN`, `GH_REPO`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_NAME`, `GITHUB_EVENT_PATH`, `PR_NUMBER`, `TEST_STAGE`, `DRY_RUN` |

## Repository variables

| Variable | Read by | Default |
| --- | --- | --- |
| `AUTO_DEPLOY_STAGE` | Deploy | Unset: Deploy runs only by hand |
| `TEST_STAGE` | Post-merge Verify | `AUTO_DEPLOY_STAGE` |
| `AWS_REGION`, `AWS_DEPLOY_ROLE_ARN`, `AWS_EXECUTION_ROLE_ARN` | Deploy, on each stage's GitHub environment | None. Deploy stops and names what is missing |
| `AWS_DOCKER_LOGIN_ROLE_ARN` | `init-monorepo`, for pulls from Amazon ECR Public | Unset: anonymous pulls |
