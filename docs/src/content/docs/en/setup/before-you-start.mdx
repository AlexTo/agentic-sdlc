A [fork of this repository](../../guides/fork-this-repo/) has everything Discava's setup keeps in
the repository. These steps add the part that lives outside it: your GitHub settings, a GitHub App
for the agents to act as, and an OpenHands installation pointed at your fork. Then you write a
spec for the notes app and watch it go from spec PR to merged agent PRs.

**Time:** about an hour, most of it waiting for the first agent run.

## What you need

On macOS or Linux (on Windows, use WSL):

| Need | Why |
| --- | --- |
| A GitHub account | To fork, write specs and review |
| GitHub CLI (`gh`), signed in | The setup script and the agents use it |
| Node.js 24 and pnpm | To run the repository and Agent Canvas |
| `uv` | Agent Canvas starts its backend with `uvx` |
| A coding agent, installed and signed in | It writes specs with Speckit, and does the agents' work inside OpenHands. Discava uses Claude Code |
| Docker (optional) | Only to run the notes app and its e2e tests on your machine. CI runs them for the agents |

<Aside type="note">
Agent Canvas runs on your own machine and polls GitHub, so it needs no public address and no
webhook. The agents only work while it is running.
</Aside>

## The steps

| # | Step | You do | You'll end with |
| --- | --- | --- | --- |
| 1 | [Fork the repository](../fork/) | Three commands | Your own copy, cloned |
| 2 | [Configure the repository](../github-repository/) | Create a GitHub App from a filled-in form, run one script | The agents' GitHub App on your fork, the labels, a protected `main`, comments limited to collaborators |
| 3 | [Install OpenHands](../openhands/) | Two commands, two profiles in the web UI | Agent Canvas running as your app, with a `developer` and a `reviewer` profile |
| 4 | [Create the two automations](../automations/) | Two forms in the web UI, one pasted prompt | The Developer and Reviewer agents implementing and reviewing in your fork |
| 5 | [Run your first feature](../first-feature/) | Write a spec, review pull requests | A spec for the notes app, carried to merged code by agents |

Want the setup in an existing repository instead? See
