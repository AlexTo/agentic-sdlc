**You'll end with:** your own fork, cloned locally, ready for the setup script.

<Steps>

1. **Fork and clone.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Make your fork the default for `gh`.** Otherwise `gh` commands, and the pull requests you
   open with it, target the original repository, not yours.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Install the dependencies.**

   ```bash
   pnpm install
   ```

   This also installs the git hooks you'll meet when you commit your first spec: Conventional
   Commits on every commit message, and a secret scan and Biome before every commit.

</Steps>

## Check it worked

```bash
gh repo set-default --view
```

prints `<you>/agentic-sdlc`.

GitHub turns Issues and Actions off in a fork. The script in the next step turns them back on.

<Aside type="tip" title="Optional: see it run">
To run what CI runs (lint, tests and build): `pnpm build`. To run the
notes app (needs Docker): `pnpm dev`, then open the URL the website prints. Neither is needed for
the setup: CI runs the checks on every pull request.
</Aside>

<Aside type="note">
With no `CODECOV_TOKEN` secret, CI's coverage upload step logs an error and carries on. Add the
secret, or delete the step, if you want it quiet.
</Aside>
