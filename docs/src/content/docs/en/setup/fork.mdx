**You'll end with:** your own fork, cloned locally, with its checks passing.

<Steps>

1. **Fork and clone.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Make your fork the default for `gh`.** Otherwise `gh` commands target the original
   repository, not yours.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Install and run the checks locally**, the same ones CI runs:

   ```bash
   pnpm install
   pnpm nx run-many --target lint --all
   pnpm nx run-many --target test --all
   pnpm nx run-many --target build --all
   ```

   `pnpm install` also installs the git hooks: Conventional Commits on every commit message, a
   secret scan and Biome before every commit, and a check of the invariant map before every
   push. To run the notes app (needs Docker): `pnpm dev`, then open the URL the website prints.

</Steps>

## Check it worked

The three `nx run-many` commands pass, and a commit with a message that isn't a Conventional
Commit is refused:

```bash
git commit --allow-empty -m "not conventional"
```

```text
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

GitHub turns Issues and Actions off in a fork. The script in the next step turns them back on.

<Aside type="note">
With no `CODECOV_TOKEN` secret, CI's coverage upload step logs an error and carries on. Add the
secret, or delete the step, if you want it quiet.
</Aside>
