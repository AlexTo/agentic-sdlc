import { Steps, Aside, FileTree } from '@astrojs/starlight/components';

**Al terminar tendrás:** `.specify/` en el repositorio, los comandos `speckit-*` disponibles para tu
agente de programación y carpetas de spec nombradas por timestamp.

<Steps>

1. **Instala la CLI**, fijada a la versión que usa Discava:

   ```bash
   uv tool install specify-cli --from "git+https://github.com/github/spec-kit.git@v1.3.2"
   specify --version
   ```

   ```text
   specify 1.3.2
   ```

2. **Copia `.specify/`** de este repositorio. Ya está configurada como la necesita el workflow:

   | Ajuste | Dónde | Valor |
   | --- | --- | --- |
   | Carpetas de spec nombradas por timestamp | `extensions/git/git-config.yml` | `branch_numbering: timestamp`, para que dos personas que escriben specs a la vez nunca choquen: `specs/20261116-013307-course-reviews/`, no `specs/001-course-reviews/` |
   | Conventional commits en cada paso | `extensions/git/git-config.yml` | `commit_style: conventional` |
   | Los hooks de la extensión git se ejecutan sin preguntar | `extensions.yml` | `auto_execute_hooks: true`: una rama antes de `/speckit-specify`, un commit después de cada paso |
   | Las plantillas y la constitución | `templates/`, `memory/` | Ya llevan los cambios del [paso 3](../constitution-and-templates/) |

3. **Añade los comandos para tu agente de programación.** Si lee skills de Claude Code, copia
   `.claude/skills/speckit-*` de este repositorio. Si no, deja que Speckit los escriba para tu
   agente en una carpeta temporal y copia solo los archivos de comandos:

   ```bash
   mkdir /tmp/speckit && cd /tmp/speckit
   specify init --here --integration <your-agent> --script sh --extension git
   ```

   Ejecuta `specify init --help` para ver la lista de integraciones. Copia la carpeta que crea para los
   comandos de tu agente, no su `.specify/`, que desharía el paso 2.

4. **Haz commit de `.specify/`** y de los archivos de comandos o skills.

</Steps>

## Comprueba que funciona

<FileTree>
- .specify/
  - extensions/git/ git-config.yml, comandos, scripts
  - extensions.yml
  - init-options.json
  - memory/constitution.md la de la app de notas, reescrita para la tuya en el siguiente paso
  - scripts/bash/
  - templates/ plantillas de spec, plan, tasks, checklist y constitución
</FileTree>

En tu agente de programación aparecen los comandos `speckit-specify`, `speckit-clarify`, `speckit-plan`, `speckit-tasks`,
`speckit-analyze` y `speckit-constitution`.

<Aside type="tip">
Los PR de spec van en su propia rama (`spec/<name>`), no en `openhands/...`. La rama de feature de la extensión git
sirve para eso. Solo las ramas del agente usan el prefijo `openhands/`.
</Aside>
