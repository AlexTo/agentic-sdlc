<CardGrid>
  <Card title="Un entorno en el que puedes confiar" icon="approve-check">
    Las reglas, los tests y los checks se organizan en capas para que un error salga a la luz y vuelva al agente, no a ti.
  </Card>
  <Card title="Escribe la spec" icon="pencil">
    Cada feature empieza como una spec, un plan y una lista de tareas revisados. El agente construye a partir de ellos, no de un chat.
  </Card>
  <Card title="Los agentes hacen el resto" icon="rocket">
    Una spec fusionada abre una issue por fase. Un agente abre el PR y corrige por sí mismo el CI en rojo o los comentarios de la revisión, hasta cinco veces por bucle.
  </Card>
  <Card title="Tú diriges" icon="information">
    Las personas aprueban la spec y tienen la última palabra antes del merge. Todo lo que ocurre entre medias funciona solo.
  </Card>
</CardGrid>
