Un [fork de este repositorio](../../guides/fork-this-repo/) tiene todo lo que la configuración de Discava guarda en
el repositorio. Estos pasos añaden la parte que vive fuera de él: tu configuración de GitHub y una
instalación de OpenHands apuntando a tu fork. Después escribes una spec para la app de notas y ves cómo
pasa de PR de spec a PR de agentes fusionados.

**Tiempo:** cerca de una hora, casi toda esperando la primera ejecución del agente.

## Lo que necesitas

| Necesitas | Por qué |
| --- | --- |
| Una cuenta de GitHub | Para hacer el fork y ser dueño del token que usan los agentes |
| Node.js 24 y pnpm | Para ejecutar el repositorio y Agent Canvas |
| `uv` | Agent Canvas arranca su backend con `uvx` |
| Docker | Solo para ejecutar la app de notas y sus tests e2e en local. CI los ejecuta para el agente |
| GitHub CLI (`gh`), con sesión iniciada | La mayoría de los pasos lo usan |
| Un agente de programación, instalado y con sesión iniciada | Escribe specs con Speckit y se ejecuta dentro de OpenHands. Discava usa Claude Code |

<Aside type="note">
Agent Canvas se ejecuta en tu propia máquina y consulta GitHub periódicamente, así que no necesita dirección pública ni
webhook. Los agentes solo trabajan mientras está en ejecución.
</Aside>
