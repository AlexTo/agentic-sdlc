**Al terminar tendrás:** tu propio fork, clonado en local y listo para el script de configuración.

<Steps>

1. **Haz fork y clona.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Haz que tu fork sea el predeterminado para `gh`.** Si no, los comandos de `gh`, y los pull requests
   que abras con él, apuntan al repositorio original, no al tuyo.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Instala las dependencias.**

   ```bash
   pnpm install
   ```

   Esto también instala los git hooks que te encontrarás al hacer commit de tu primera spec: Conventional
   Commits en cada mensaje de commit, y un escaneo de secrets y Biome antes de cada commit.

</Steps>

## Comprueba que funciona

```bash
gh repo set-default --view
```

imprime `<you>/agentic-sdlc`.

GitHub desactiva Issues y Actions en un fork. El script del siguiente paso los vuelve a activar.

<Aside type="tip" title="Opcional: verlo funcionar">
Para ejecutar lo que ejecuta CI (lint, tests y build): `pnpm build`. Para ejecutar la
app de notas (necesita Docker): `pnpm dev`, y abre la URL que imprime el sitio web. Ninguna de las dos cosas
hace falta para la configuración: CI ejecuta los checks en cada pull request.
</Aside>

<Aside type="note">
Sin el secret `CODECOV_TOKEN`, el paso de subida de cobertura de CI registra un error y continúa. Añade el
secret, o borra el paso, si quieres que no haga ruido.
</Aside>
