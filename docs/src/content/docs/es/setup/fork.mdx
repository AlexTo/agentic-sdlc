**Al terminar tendrás:** tu propio fork, clonado en local y con sus checks pasando.

<Steps>

1. **Haz fork y clona.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Haz que tu fork sea el predeterminado para `gh`.** Si no, los comandos de `gh` apuntan al repositorio
   original, no al tuyo.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Instala y ejecuta los checks en local**, los mismos que ejecuta CI:

   ```bash
   pnpm install
   pnpm nx run-many --target lint --all
   pnpm nx run-many --target test --all
   pnpm nx run-many --target build --all
   ```

   `pnpm install` también instala los git hooks: Conventional Commits en cada mensaje de commit, un
   escaneo de secrets y Biome antes de cada commit, y una comprobación del mapa de invariantes antes de
   cada push. Para ejecutar la app de notas (necesita Docker): `pnpm dev`, y abre la URL que imprime el sitio web.

</Steps>

## Comprueba que funciona

Los tres comandos `nx run-many` pasan, y un commit cuyo mensaje no es un Conventional Commit se
rechaza:

```bash
git commit --allow-empty -m "not conventional"
```

```text
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

GitHub desactiva Issues y Actions en un fork. El script del siguiente paso los vuelve a activar.

<Aside type="note">
Sin el secret `CODECOV_TOKEN`, el paso de subida de cobertura de CI registra un error y continúa. Añade el
secret, o borra el paso, si quieres que no haga ruido.
</Aside>
