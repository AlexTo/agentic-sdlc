**Résultat :** votre propre fork, cloné en local, avec ses checks qui passent.

<Steps>

1. **Forkez et clonez.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Faites de votre fork le dépôt par défaut de `gh`.** Sinon, les commandes `gh` ciblent le dépôt
   d'origine, pas le vôtre.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Installez et lancez les checks en local**, les mêmes que ceux de la CI :

   ```bash
   pnpm install
   pnpm nx run-many --target lint --all
   pnpm nx run-many --target test --all
   pnpm nx run-many --target build --all
   ```

   `pnpm install` installe aussi les hooks git : Conventional Commits sur chaque message de commit, un
   scan de secrets et Biome avant chaque commit, et une vérification de la carte des invariants avant chaque
   push. Pour lancer l'application de notes (Docker requis) : `pnpm dev`, puis ouvrez l'URL qu'affiche le site web.

</Steps>

## Vérifier que ça marche

Les trois commandes `nx run-many` passent, et un commit dont le message n'est pas un Conventional
Commit est refusé :

```bash
git commit --allow-empty -m "not conventional"
```

```text
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

GitHub désactive Issues et Actions dans un fork. Le script de l'étape suivante les réactive.

<Aside type="note">
Sans secret `CODECOV_TOKEN`, l'étape d'envoi de la couverture de la CI journalise une erreur et continue. Ajoutez le
secret, ou supprimez l'étape, si vous voulez qu'elle se taise.
</Aside>
