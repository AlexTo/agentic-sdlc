**Résultat :** votre propre fork, cloné en local, prêt pour le script de configuration.

<Steps>

1. **Forkez et clonez.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Faites de votre fork le dépôt par défaut de `gh`.** Sinon, les commandes `gh`, et les pull requests
   que vous ouvrez avec lui, ciblent le dépôt d'origine, pas le vôtre.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Installez les dépendances.**

   ```bash
   pnpm install
   ```

   Cela installe aussi les hooks git que vous rencontrerez en commitant votre première spec : Conventional
   Commits sur chaque message de commit, et un scan de secrets et Biome avant chaque commit.

</Steps>

## Vérifier que ça marche

```bash
gh repo set-default --view
```

affiche `<you>/agentic-sdlc`.

GitHub désactive Issues et Actions dans un fork. Le script de l'étape suivante les réactive.

<Aside type="tip" title="Facultatif : le voir tourner">
Pour lancer ce que lance la CI (lint, tests et build) : `pnpm build`. Pour lancer
l'application de notes (Docker requis) : `pnpm dev`, puis ouvrez l'URL qu'affiche le site web. Ni l'un ni l'autre
n'est nécessaire à la configuration : la CI lance les checks sur chaque pull request.
</Aside>

<Aside type="note">
Sans secret `CODECOV_TOKEN`, l'étape d'envoi de la couverture de la CI journalise une erreur et continue. Ajoutez le
secret, ou supprimez l'étape, si vous voulez qu'elle se taise.
</Aside>
