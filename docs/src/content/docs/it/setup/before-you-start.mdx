Un [fork di questo repository](../../guides/fork-this-repo/) contiene tutto ciò che la configurazione di Discava tiene
nel repository. Questi passaggi aggiungono la parte che vive fuori: le impostazioni di GitHub e
un'installazione di OpenHands puntata sul tuo fork. Poi scrivi una spec per l'app di note e la guardi
passare dalla PR della spec alle PR degli agenti unite.

**Tempo:** circa un'ora, quasi tutta in attesa della prima esecuzione dell'agente.

## Cosa ti serve

| Requisito | Perché |
| --- | --- |
| Un account GitHub | Per fare il fork, scrivere le spec e fare review |
| Una GitHub App per gli agenti | Gli agenti agiscono come essa, così le loro PR e i loro commenti sono loro e puoi approvarli. Quella di Discava è `alex-coding-agent` |
| Node.js 24 e pnpm | Per eseguire il repository e Agent Canvas |
| `uv` | Agent Canvas avvia il suo backend con `uvx` |
| `openssl`, `curl` e `jq` | Per creare i token dell'app |
| Docker | Solo per eseguire in locale l'app di note e i suoi test e2e. La CI li esegue per l'agente |
| GitHub CLI (`gh`), con accesso effettuato | La usano quasi tutti i passaggi |
| Un coding agent, installato e con accesso effettuato | Scrive le spec con Speckit, e gira dentro OpenHands. Discava usa Claude Code |

<Aside type="note">
Agent Canvas gira sulla tua macchina e interroga GitHub, quindi non servono un indirizzo pubblico né un
webhook. Gli agenti lavorano solo mentre è in esecuzione.
</Aside>
