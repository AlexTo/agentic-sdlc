**Alla fine avrai:** il tuo fork, clonato in locale, con i suoi check che passano.

<Steps>

1. **Fai il fork e clonalo.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Rendi il tuo fork il predefinito per `gh`.** Altrimenti i comandi `gh` puntano al repository
   originale, non al tuo.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Installa ed esegui i check in locale**, gli stessi che esegue la CI:

   ```bash
   pnpm install
   pnpm nx run-many --target lint --all
   pnpm nx run-many --target test --all
   pnpm nx run-many --target build --all
   ```

   `pnpm install` installa anche gli hook git: Conventional Commits su ogni messaggio di commit, una
   scansione dei secret e Biome prima di ogni commit, e un controllo della mappa degli invarianti prima
   di ogni push. Per eseguire l'app di note (serve Docker): `pnpm dev`, poi apri l'URL che stampa il sito.

</Steps>

## Verifica che funzioni

I tre comandi `nx run-many` passano, e un commit con un messaggio che non è un Conventional Commit
viene rifiutato:

```bash
git commit --allow-empty -m "not conventional"
```

```text
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

GitHub disattiva Issues e Actions in un fork. Lo script del passaggio successivo li riattiva.

<Aside type="note">
Senza il secret `CODECOV_TOKEN`, il passaggio di upload della coverage della CI registra un errore e
prosegue. Aggiungi il secret, o elimina il passaggio, se vuoi che taccia.
</Aside>
