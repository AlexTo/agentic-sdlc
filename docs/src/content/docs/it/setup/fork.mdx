**Alla fine avrai:** il tuo fork, clonato in locale, pronto per lo script di configurazione.

<Steps>

1. **Fai il fork e clonalo.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Rendi il tuo fork il predefinito per `gh`.** Altrimenti i comandi `gh`, e le pull request che
   apri con `gh`, puntano al repository originale, non al tuo.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Installa le dipendenze.**

   ```bash
   pnpm install
   ```

   Questo installa anche gli hook git che incontrerai quando farai il commit della tua prima spec:
   Conventional Commits su ogni messaggio di commit, e una scansione dei secret e Biome prima di
   ogni commit.

</Steps>

## Verifica che funzioni

```bash
gh repo set-default --view
```

stampa `<you>/agentic-sdlc`.

GitHub disattiva Issues e Actions in un fork. Lo script del passaggio successivo li riattiva.

<Aside type="tip" title="Facoltativo: guardalo girare">
Per eseguire ciò che esegue la CI (lint, test e build): `pnpm build`. Per eseguire l'app di note
(serve Docker): `pnpm dev`, poi apri l'URL che stampa il sito. Nessuno dei due serve per la
configurazione: la CI esegue i check su ogni pull request.
</Aside>

<Aside type="note">
Senza il secret `CODECOV_TOKEN`, il passaggio di upload della coverage della CI registra un errore e
prosegue. Aggiungi il secret, o elimina il passaggio, se vuoi che taccia.
</Aside>
