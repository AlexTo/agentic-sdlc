**このステップで得られるもの:** 批准された自分の憲章と、Agent Issues workflow が読めるファイルを生成する
Speckit のテンプレート。

[ステップ 2](../speckit/) でコピーした `.specify/` には、notes アプリ向けに書かれた、動作する憲章とテンプレートが
すでに入っています。このステップでそれらを自分のものにします。

<Steps>

1. **憲章を自分のプロジェクト用に書き直します。** コーディングエージェントで次を実行します。

   ```text
   /speckit-constitution
   ```

   プロジェクト独自の原則を渡します。アーキテクチャ、データモデル、セキュリティのデフォルト、コードの規約です。
   [Discava の憲章](../../discava/constitution-and-guidance/) が完全な例です。コピーした憲章のうち次の部分は、
   コマンドとパッケージ名を自分のスタックに合わせたうえで残してください。workflow の残りの部分がこれらに依存しているためです。

   | 残すもの | コピーした憲章の該当箇所 | 理由 |
   | --- | --- | --- |
   | ユニットテスト、invariant、e2e テストは必須で、テストは仕様である | III. Layered Tests | エージェントが CI を緑にするためにテストを弱めてはならない |
   | すべてがクラウドアカウントなしで `pnpm dev` の下で動く | II. Everything Runs Locally | それによって PR の CI で e2e スイートを実行し、エージェントに本当のフィードバックを返せる |
   | エージェントは自分のブランチと PR で実装し、ローカルスタックを決して実行せず、それが必要なタスクには **(human)** を付ける | Development Workflow | エージェントには Docker がない。エージェントが実行できないものは CI が実行する |
   | PR の CI が関門である。エージェントは決してマージせず、`main` に push せず、CI の workflow を編集せず、テストを弱めない | Development Workflow | エージェントを自分の持ち場にとどめるもの |

2. **`tasks-template.md` のパッケージのパスを変更します。** そのテストタスクは、このリポジトリのパッケージ
   `packages/notes-table/src/helpers/invariants/` と `@agentic-sdlc/e2e` を指しています。自分のものに向けてください。
   テンプレートの残りはそのままにします。**Read by automation** の下のフォーマットのルール、**(human)** の印、
   必須のテスト、既存のテストを編集しないようにという注記は、Agent Issues workflow と `Tasks format` チェックが
   頼りにしているものです。

3. `spec-template.md` の **親 issue の行を残します**。

   ```markdown
   **Parent issue**: [#<number>, or "none" if there is no tracking issue]
   ```

   Agent Issues はこれをもとに、各 issue に `Refs #<parent>` を書き込みます。

</Steps>

## 動作を確認する

小さな機能について、使い捨ての spec とタスクを生成します。そして、グルースクリプトが揃ったら
（[ステップ 5](../glue-scripts/)）次を実行します。

```bash
pnpm nx run @your-scope/tooling-agent:validate-tasks
```

```text
1 tasks.md file(s) are in the expected format.
```

確認が終わったら、使い捨ての spec フォルダーは削除します。

<Aside type="caution">
`/speckit-tasks` はときどき `### Phase 2` と書いたり、タスクをインデントしたりします。それこそが validator が
検出するものなので、validator を緩めないでください。生成されたファイルが通るまで、テンプレートの文言を修正します。
</Aside>
