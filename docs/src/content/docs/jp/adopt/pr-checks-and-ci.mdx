**最終的に手に入るもの:** 失敗が CI ループに渡される **PR Checks** workflow、**UI Screenshots**
チェック、そして `main` の **CI**。

<Steps>

1. このリポジトリの `.github/workflows/` から **4 つの workflow をコピーします**。

   | ファイル | 役割 |
   | --- | --- |
   | `pr-checks.yml` | PR が影響するものの lint、test、build。`Tasks format`。`Invariant coverage`。シャード分割され、1 つの `E2E tests` チェックにまとめられる e2e。`E2E screenshots` コメント |
   | `ui-screenshots.yml` | スクリーンショットのルール。独立した workflow なので、`no-ui-screenshots` ラベルを付け外しするとこのチェックだけが再実行される。Discava は代わりに PR Checks のジョブとして実行している。どちらでも構わない |
   | `ci.yml` | `main` への push のたびに同じチェック、Trivy、Playwright のキャッシュ、このドキュメントサイトのデプロイ |
   | `cache-cleanup.yml` | PR がクローズされたときにその PR のキャッシュを削除する |

   `pr-checks.yml` の `name: PR Checks` はそのまま残してください。Agent CI Status はその名前の workflow を
   待ち受けています。

2. **自分のプロジェクトに向けます。** コピーしたファイルで `@agentic-sdlc/` を検索し、スコープを変更します。
   続いて `pr-checks.yml` で次を変更します。

   | ジョブ | 変更するもの |
   | --- | --- |
   | `invariant-coverage` | テーブルに書き込む可能性のあるコードの `paths`。ステップ 5 の `WRITER_PACKAGES` と同じ。まだ invariant をチェックしないなら、このジョブを削除する |
   | `e2e` | `matrix.shard` のシャード数を自分のテストスイートに合わせる。1 つのシャードは最初のテストまでに約 2 分かかるので、各シャードのテストがそれくらいの時間になったら追加をやめる |
   | `e2e-screenshots` | [ステップ 8](../local-stack-and-e2e/) を終えたら、何もない |

   `ci.yml` では、`docs/` からドキュメントサイトを公開するのでなければ、`deploy_docs` ジョブとその
   `pages: write` 権限を削除します。

3. **エージェントを速く保つものは残します。** `ci.yml` の `Check for mutations` ステップ（build の後の `git diff
   --exit-code`）は、エージェントがコミットし忘れた生成ファイルを見つけます。`playwright-cache` ジョブは
   `main` から Chromium を保存します。PR の実行は `main` で保存されたキャッシュしか復元できないためです。
   `build` ジョブは `main` から Nx のタスクキャッシュを保存するので、PR の最初の実行では `main` がすでにビルドしたものが
   再生され、修正のたびにエージェントが待つ時間が減ります。PR Checks の各 `checks` レグも同じように自分のキャッシュを
   保持しますが、`lint` だけは復元のみです。`init-monorepo` はキャッシュを 1 GB までに制限し、Cache Cleanup は
   クローズされた PR がリポジトリの 10 GB のうちに占めていた分を解放します。これで Discava がどれだけ節約できたかは
   [速さを保つ](../../discava/pr-checks/#速さを保つ) を参照してください。

</Steps>

すべての action はコミット SHA に固定されていて、ステップ 1 でコピーした `dependabot.yml` がその固定を最新に保ちます。

## 動作を確認する

たとえばタスクをインデントするなどして、`tasks.md` の 1 行を壊す使い捨ての PR を開きます。
**Tasks format** チェックが、その行に注釈を付けて失敗します。

```text
A task must be written "- [ ] T<3 digits> <description>", starting in the first column
```

もう 1 つ、シナリオには触れずに UI ファイルを変更する PR を開きます。**UI Screenshots** が失敗します。

```text
This pull request changes UI source (…) but no e2e scenario gained a `screenshot(page, 'name')` call.
```

<Aside type="note">
コピーしたファイルの `codecov/codecov-action` には `CODECOV_TOKEN` シークレットが必要です。Codecov を
使わないなら、そのステップを削除してください。
</Aside>
