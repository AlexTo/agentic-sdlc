<CardGrid>
  <Card title="信頼できる環境" icon="approve-check">
    ルール、テスト、チェックを層にして、ミスが表に出たら、あなたではなくエージェントに戻るようにします。
  </Card>
  <Card title="spec を書く" icon="pencil">
    すべての機能は、レビュー済みの spec、plan、タスクリストから始まります。エージェントはチャットではなく、それらをもとに実装します。
  </Card>
  <Card title="残りはエージェントが行う" icon="rocket">
    spec がマージされると、フェーズごとに issue が開かれます。エージェントが PR を開き、赤い CI やレビューのフィードバックを自分で修正します。1 つのループにつき最大 5 回までです。
  </Card>
  <Card title="あなたは舵を取る" icon="information">
    人は spec を承認し、マージ前に最終判断を下します。その間のすべては自動で進みます。
  </Card>
</CardGrid>
