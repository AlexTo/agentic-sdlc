各要素が互いを直接呼び出すことはありません。GitHub にシグナルを残し、次の要素がそれを探します。

## コミットステータス

| 項目 | 値 |
| --- | --- |
| Context | `software-factory/review` |
| State | `failure` のみ。成功した実行や承認では何も投稿しない |
| 投稿先 | 失敗した時点での PR の head コミット |
| 投稿者 | Agent CI Status、Agent Review Status、または人 |
| Description | `CI failed (fix attempt <n> of 5): <failed jobs>` または `Review requested changes (fix attempt <n> of 5): see the review`。最大 140 文字 |
| Target URL | 失敗した実行、またはレビュー |
| 読む人 | issue-to-PR ワーカー。head のこのステータスが `failure` または `error` のとき PR を修正する |

新しい push はこのステータスなしで始まるので、エージェントが push するとワーカーは修正をやめます。

## 隠れたマーカー

| マーカー | 場所 | 書く人 | 用途 |
| --- | --- | --- | --- |
| `<!-- agent-issue spec:<folder> group:<n> -->` | 実装 issue の 1 行目 | Agent Issues | マージされたエージェントの PR から（その `Closes #n` を通じて）spec フォルダを見つけ、同じグループに 2 つ目の issue を開かないようにする |
| `<!-- post-merge-test pr:<n> -->` | テスト issue の 1 行目 | Post-merge Verify | 同じ pull request に 2 つ目のテスト issue を開かないようにする |
| `<!-- openhands-review-run: <id> -->` | レビュー担当エージェントの各レビュー | Code review automation | Agent Review Status はこれを含むレビューだけを処理する |
| `<!-- openhands-review-gate:waiting:<sha> -->` | 「Review waiting on checks」コメント | Code review automation | その head を待っていることをレビュアー自身が記録する |
| `<!-- e2e-screenshots -->` | E2E スクリーンショットのコメント | PR Checks | 実行のたびに新しいコメントを追加せず、1 つのコメントを更新する |

issue 内のマーカーが有効なのは、その issue を workflow 自身のアカウントか書き込み権限のある人が開いた場合だけです。
マーカーを含む issue は誰でも開けます。

## 判定の行

レビュー担当は各レビューの最後に、次のどちらかを単独の行で書きます。

```text
✅ APPROVED
🔄 CHANGES REQUESTED
```

Agent Review Status は、単独の行にある `^🔄 CHANGES REQUESTED\s*$` に一致させます。文中でこのフレーズに
触れているだけのレビューはカウントされません。

## ブランチ名

| パターン | 誰が | 重要な理由 |
| --- | --- | --- |
| `openhands/issue-<n>` | Issue-to-PR automation | ワーカーが修正する唯一のブランチで、修正の workflow が応答する唯一のブランチ |
| `openhands/issue-<n>-2`、… | Issue-to-PR automation（ラベルを付け直した issue で） | 自動では修正されない |
| `openhands/test-fix-<n>` | Issue tester automation（テスト issue `<n>` に対して） | テスト担当がテスト中に見つけた修正。自動では修正されない |
| `openhands/` で始まるすべて | エージェントのブランチ | マージするとチェーンが進む。Discava では、ここからの pull request は開かれた時点でロックされる |
| `spec/<name>`（ほかの任意の名前） | 人 | `spec-ready` がある場合にのみチェーンが進む |
