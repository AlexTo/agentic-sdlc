[このリポジトリの fork](../../guides/fork-this-repo/) には、Discava のセットアップのうちリポジトリ内に
置かれているものがすべて含まれています。これらの手順では、リポジトリの外にある部分、つまり GitHub の設定、
エージェントが動くための GitHub App、そして fork を対象にした OpenHands のインストールを追加します。
その後、notes アプリの spec を書き、spec PR からマージされたエージェントの PR になるまでを見届けます。

**所要時間:** 約 1 時間。大半は最初のエージェント実行の待ち時間です。

## 必要なもの

macOS または Linux で (Windows では WSL を使います):

| 必要なもの | 理由 |
| --- | --- |
| GitHub アカウント | fork し、spec を書き、レビューするため |
| サインイン済みの GitHub CLI (`gh`) | セットアップスクリプトとエージェントが使います |
| Node.js 24 と pnpm | リポジトリと Agent Canvas を実行するため |
| `uv` | Agent Canvas は `uvx` でバックエンドを起動します |
| インストール済みでサインイン済みのコーディングエージェント | Speckit で spec を書き、OpenHands の中でエージェントの作業を行います。Discava は Claude Code を使っています |
| Docker (任意) | notes アプリとその e2e テストを自分のマシンで実行する場合のみ。エージェント向けには CI が実行します |

<Aside type="note">
Agent Canvas は自分のマシン上で動き、GitHub をポーリングするので、公開アドレスも webhook も
不要です。エージェントは Agent Canvas が動いている間だけ作業します。
</Aside>

## 手順

| # | 手順 | やること | 完了時の状態 |
| --- | --- | --- | --- |
| 1 | [リポジトリを fork する](../fork/) | 3 つのコマンド | クローン済みの自分のコピー |
| 2 | [リポジトリを設定する](../github-repository/) | 入力済みのフォームから GitHub App を作成し、スクリプトを 1 つ実行する | fork に入ったエージェントの GitHub App、ラベル、保護された `main`、コラボレーターに限定したコメント |
| 3 | [OpenHands をインストールする](../openhands/) | 2 つのコマンドと、Web UI での 2 つのプロファイル | 自分の App として動く Agent Canvas と、`developer` と `reviewer` のプロファイル |
| 4 | [2 つの automation を作成する](../automations/) | Web UI での 2 つのフォームと、貼り付けるプロンプト 1 つ | fork で実装とレビューを行う開発担当エージェントとレビュー担当エージェント |
| 5 | [最初の機能を実行する](../first-feature/) | spec を書き、pull request をレビューする | エージェントによってマージ済みのコードまで運ばれた notes アプリの spec |

代わりに既存のリポジトリでセットアップしたい場合は、
[自分のリポジトリに導入する](../../adopt/overview/) を参照してください。

次へ: [1. リポジトリを fork する](../fork/)。
