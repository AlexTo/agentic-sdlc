**完了時の状態:** ローカルにクローンされ、チェックが通る自分の fork。

<Steps>

1. **fork してクローンします。**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **自分の fork を `gh` のデフォルトにします。** そうしないと、`gh` コマンドは自分のリポジトリではなく
   元のリポジトリを対象にします。

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. CI と同じ **チェックをローカルでインストールして実行します**:

   ```bash
   pnpm install
   pnpm nx run-many --target lint --all
   pnpm nx run-many --target test --all
   pnpm nx run-many --target build --all
   ```

   `pnpm install` は git フックもインストールします。すべてのコミットメッセージに Conventional Commits、
   すべてのコミット前にシークレットスキャンと Biome、すべての push 前に invariant マップのチェックが行われます。
   notes アプリを実行するには(Docker が必要): `pnpm dev` を実行し、ウェブサイトが表示する URL を開きます。

</Steps>

## 動作を確認する

3 つの `nx run-many` コマンドが通り、Conventional Commit ではないメッセージのコミットは拒否されます。

```bash
git commit --allow-empty -m "not conventional"
```

```text
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

GitHub は fork で Issues と Actions を無効にします。次のステップのスクリプトがそれらを有効に戻します。

<Aside type="note">
`CODECOV_TOKEN` シークレットがないと、CI のカバレッジのアップロードステップはエラーをログに出して続行します。
静かにしたい場合は、シークレットを追加するか、そのステップを削除してください。
</Aside>
