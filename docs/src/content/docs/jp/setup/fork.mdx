**完了時の状態:** ローカルにクローンされ、セットアップスクリプトを実行できる状態の自分の fork。

<Steps>

1. **fork してクローンします。**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **自分の fork を `gh` のデフォルトにします。** そうしないと、`gh` コマンドも、それで開く pull request も、
   自分のリポジトリではなく元のリポジトリを対象にします。

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **依存関係をインストールします。**

   ```bash
   pnpm install
   ```

   これは、最初の spec をコミットするときに出会う git フックもインストールします。すべてのコミットメッセージに
   Conventional Commits、すべてのコミット前にシークレットスキャンと Biome が行われます。

</Steps>

## 動作を確認する

```bash
gh repo set-default --view
```

が `<you>/agentic-sdlc` を表示します。

GitHub は fork で Issues と Actions を無効にします。次のステップのスクリプトがそれらを有効に戻します。

<Aside type="tip" title="任意: 動かしてみる">
CI が実行するもの (lint、テスト、ビルド) を実行するには: `pnpm build`。notes アプリを実行するには
(Docker が必要): `pnpm dev` を実行し、ウェブサイトが表示する URL を開きます。どちらもセットアップには
必要ありません。CI がすべての pull request でチェックを実行します。
</Aside>

<Aside type="note">
`CODECOV_TOKEN` シークレットがないと、CI のカバレッジのアップロードステップはエラーをログに出して続行します。
静かにしたい場合は、シークレットを追加するか、そのステップを削除してください。
</Aside>
