**결과:** 실패가 CI 루프로 이어지는 **PR Checks** workflow, **UI Screenshots**
검사, 그리고 `main`의 **CI**.

<Steps>

1. 이 저장소의 `.github/workflows/`에서 **workflow 네 개를 복사**합니다.

   | 파일 | 하는 일 |
   | --- | --- |
   | `pr-checks.yml` | PR이 영향을 주는 것의 lint, test, build; `Tasks format`; `Invariant coverage`; 하나의 `E2E tests` 검사로 모이는 샤드로 나뉜 e2e; `E2E screenshots` 댓글 |
   | `ui-screenshots.yml` | 스크린샷 규칙을 별도의 workflow로 실행하므로, `no-ui-screenshots` label을 추가하거나 제거하면 이 검사만 다시 실행됩니다. Discava는 대신 PR Checks의 job으로 실행합니다. 어느 쪽이든 됩니다 |
   | `ci.yml` | `main`으로의 모든 push에서 같은 검사, Trivy, Playwright 캐시, 그리고 이 문서 사이트의 배포 |
   | `cache-cleanup.yml` | PR이 닫히면 그 PR의 캐시를 삭제 |

   `pr-checks.yml`의 `name: PR Checks`는 정확히 그대로 두세요. Agent CI Status가 그 이름의 workflow를
   기다립니다.

2. **workflow가 여러분의 프로젝트를 가리키게 합니다.** 복사한 파일에서 `@agentic-sdlc/`를 찾아 scope를
   바꿉니다. 그다음 `pr-checks.yml`에서:

   | Job | 바꿀 것 |
   | --- | --- |
   | `invariant-coverage` | 테이블에 쓸 수 있는 코드의 `paths`. 5단계의 `WRITER_PACKAGES`와 같습니다. 아직 invariant를 검사하지 않는다면 job을 삭제하세요 |
   | `e2e` | `matrix.shard`의 샤드 수를 여러분의 suite에 맞게. 샤드 하나는 첫 테스트 전까지 약 2분이 걸리므로, 각 샤드의 테스트가 그 정도 걸리게 되면 샤드를 더 추가하지 마세요 |
   | `e2e-screenshots` | [8단계](../local-stack-and-e2e/)를 마치면 바꿀 것 없음 |

   `docs/`에서 문서 사이트를 게시하지 않는다면, `ci.yml`에서 `deploy_docs` job과 그 `pages: write` 권한을
   삭제하세요.

3. **에이전트를 빠르게 유지하는 것은 그대로 둡니다.** `ci.yml`의 `Check for mutations` step (build 후의
   `git diff --exit-code`)은 에이전트가 커밋하는 것을 잊은 생성 파일을 잡아냅니다. `playwright-cache` job은
   `main`에서 Chromium을 저장합니다. PR 실행은 `main`에서 저장된 캐시만 복원할 수 있기 때문입니다. `build`
   job은 `main`에서 Nx의 task 캐시를 저장하므로, PR의 첫 실행은 `main`이 이미 build한 것을 재생하고,
   에이전트는 매 수정 라운드마다 덜 기다립니다. PR Checks의 각 `checks` 갈래도 같은 방식으로 자신의 캐시를
   유지하지만, `lint`는 예외로 복원만 합니다. `init-monorepo`는 캐시를 1 GB로 제한하고, Cache Cleanup은
   저장소의 10 GB 중 닫힌 PR이 차지하던 몫을 비웁니다. 이것으로 Discava가 얼마나 절약했는지는
   [빠르게 유지하기](../../discava/pr-checks/#빠르게-유지하기)를 참고하세요.

</Steps>

모든 action은 커밋 SHA로 고정되어 있으며, 1단계에서 복사한 `dependabot.yml`이 고정한 버전을 최신으로
유지합니다.

## 동작 확인

`tasks.md`의 한 줄을 깨뜨리는 버릴 PR을 엽니다. 예를 들어 task를 들여씁니다.
**Tasks format** 검사가 그 줄에 annotation을 달며 실패합니다.

```text
A task must be written "- [ ] T<3 digits> <description>", starting in the first column
```

시나리오는 건드리지 않고 UI 파일을 바꾸는 PR을 하나 더 엽니다. **UI Screenshots**가 실패합니다.

```text
This pull request changes UI source (…) but no e2e scenario gained a `screenshot(page, 'name')` call.
```

<Aside type="note">
복사한 파일의 `codecov/codecov-action`에는 `CODECOV_TOKEN` secret이 필요합니다. Codecov를 쓰지 않는다면
그 step을 제거하세요.
</Aside>
