**결과:** 실패가 CI 루프로 이어지는 **PR Checks** workflow, **UI Screenshots**
검사, 그리고 `main`의 **CI**.

<Steps>

1. 이 저장소에서 **`.github/workflows/pr-checks.yml`을 복사**합니다. `name: PR Checks`는
   정확히 그대로 두세요. Agent CI Status가 그 이름의 workflow를 기다립니다. job은 다음과 같습니다.

   | Job | 그대로 둘까요? |
   | --- | --- |
   | `checks`, `fail-fast: false`인 `lint`, `test`, `build`의 matrix | 예 |
   | `tasks-format` | 예 |
   | 샤드로 나뉜 `e2e`, 그리고 샤드를 하나의 `E2E tests` 검사로 모으는 `e2e-result` | 샤드 수를 여러분의 suite에 맞게 설정합니다 |
   | `e2e-screenshots` | 예, [8단계](../local-stack-and-e2e/)를 마친 뒤에 |

2. **`.github/workflows/ui-screenshots.yml`을 복사**합니다. 이 저장소에서 스크린샷 규칙은
   `opened, synchronize, reopened, labeled, unlabeled`에서 trigger되는 별도의 workflow입니다. 그래서
   `no-ui-screenshots` label을 추가하거나 제거하면 전체 e2e suite가 아니라 이 검사만 다시 실행됩니다.
   Discava는 대신 같은 규칙을 PR Checks의 job으로 실행합니다. 어느 쪽이든 됩니다.

3. `main`으로의 push를 위해 **`.github/workflows/ci.yml`을 복사**합니다. `Check for mutations` step
   (build 후의 `git diff --ignore-space-at-eol --exit-code`)은 유지하세요. 에이전트가 커밋하는 것을 잊은
   생성 파일을 잡아냅니다. Playwright를 쓴다면 `playwright-cache` job도 유지하세요. PR 실행은 `main`에서
   저장된 캐시만 복원할 수 있습니다.

   `build` job은 `init-monorepo`에 `nx-cache-scope: main`을 넘겨 Nx의 task 캐시를 저장합니다.
   PR의 첫 실행은 이 캐시에서 시작하므로, `main`이 이미 build한 입력을 가진 task는 다시 실행되지 않고
   재생되며, 에이전트는 매 수정 라운드마다 덜 기다립니다. PR Checks의 각 `checks` 갈래도 같은 방식으로
   자신의 캐시를 유지하지만, `lint`는 예외로 복원만 합니다. lint가 캐시를 저장하는 것보다 빠르기 때문입니다.
   `init-monorepo`는 캐시를 1 GB로 제한합니다.

4. **`.github/workflows/cache-cleanup.yml`을 복사**합니다. PR이 닫히면 그 PR의 캐시를 삭제합니다.
   다른 어떤 것도 그 캐시를 읽을 수 없으며, 이 workflow가 없으면 GitHub가 제거할 때까지 저장소의
   10 GB Actions 캐시 용량을 차지하고, GitHub는 아직 열려 있는 PR의 캐시부터 제거합니다. 이것으로 Discava가
   얼마나 절약했는지는 [빠르게 유지하기](../../discava/pr-checks/#빠르게-유지하기)를 참고하세요.

5. 복사한 파일처럼 **모든 action을 커밋 SHA로 고정**하고, 고정한 버전이 최신으로 유지되도록
   `.github/dependabot.yml`을 추가합니다.

   ```yaml
   version: 2
   updates:
     - package-ecosystem: 'npm'
       directory: '/'
       schedule: { interval: 'weekly' }
       groups: { all: { patterns: ['*'] } }
     - package-ecosystem: 'github-actions'
       directories: ['/', '/.github/actions/*']
       schedule: { interval: 'weekly' }
       groups: { github-actions: { applies-to: version-updates, patterns: ['*'] } }
   ```

</Steps>

## 동작 확인

`tasks.md`의 한 줄을 깨뜨리는 버릴 PR을 엽니다. 예를 들어 task를 들여씁니다.
**Tasks format** 검사가 그 줄에 annotation을 달며 실패합니다.

```text
A task must be written "- [ ] T<3 digits> <description>", starting in the first column
```

시나리오는 건드리지 않고 UI 파일을 바꾸는 PR을 하나 더 엽니다. **UI Screenshots**가 실패합니다.

```text
This pull request changes UI source (…) but no e2e scenario gained a `screenshot(page, 'name')` call.
```

<Aside type="note">
복사한 파일의 `codecov/codecov-action`에는 `CODECOV_TOKEN` secret이 필요합니다. Codecov를 쓰지 않는다면
그 step을 제거하세요.
</Aside>
