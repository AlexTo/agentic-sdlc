| Workflow | 파일 | Trigger | 권한 | Checkout 대상 |
| --- | --- | --- | --- | --- |
| PR Checks | `pr-checks.yml` | `main`으로의 `pull_request` | `contents: read`, 그리고 스크린샷 댓글 job에 `pull-requests: write` | PR |
| UI Screenshots | `ui-screenshots.yml` | `labeled`/`unlabeled`를 포함한 `main`으로의 `pull_request` | `contents: read`, `pull-requests: read` | 기본 브랜치 (API에서 diff를 읽음) |
| CI | `ci.yml` | `main`으로의 `push`, `workflow_dispatch` | `contents: read`, `pages: write`, `id-token: write` | `main` |
| Agent Issues | `agent-issues.yml` | `main`으로의 `pull_request: [closed, labeled]`, `workflow_dispatch(spec_folder)` | `contents: read`, `issues: write`, `pull-requests: write` | merge 커밋 |
| Archive Specs | `archive-specs.yml` | `specs/*/tasks.md`를 바꾸는 `main`으로의 `push`, `workflow_dispatch` | `contents: write`, `issues: read`, `pull-requests: write` | `main` |
| Agent CI Status | `agent-ci.yml` | PR Checks의 `workflow_run`, `completed` | `contents: read`, `actions: read`, `statuses: write`, `issues: write`, `pull-requests: write` | 기본 브랜치 |
| Agent Review Status | `agent-review.yml` | `pull_request_review: submitted` | `contents: read`, `statuses: write`, `issues: write`, `pull-requests: write` | 기본 브랜치 |
| Cache Cleanup | `cache-cleanup.yml` | `pull_request: closed` | `actions: write` | 없음 (PR 번호를 `gh`에 전달) |
| Deploy (Discava) | `deploy.yml` | `main`에서 CI의 `workflow_run`, `workflow_dispatch(stage)` | `contents: read`, `id-token: write` | CI가 검증한 커밋 |

## Branch protection에서 필수로 지정할 job 이름

| Check | 출처 |
| --- | --- |
| `Checks (lint)`, `Checks (test)`, `Checks (build)` | PR Checks |
| `Tasks format` | PR Checks |
| `E2E tests` | PR Checks (샤드를 모음) |
| `UI Screenshots` | UI Screenshots |

## Concurrency 그룹

| Workflow | 그룹 | 진행 중 취소 |
| --- | --- | --- |
| PR Checks | `pr-checks-<ref>` | 예: 새 push가 이전 실행을 무의미하게 만듭니다 |
| Agent Issues | `agent-issues-<PR number or folder>` | 아니요 |
| Archive Specs | `archive-specs` | 아니요: 한 번에 하나만 실행되므로 두 실행이 같은 PR을 열지 않습니다 |
| Agent CI Status | `agent-ci-<head branch>` | 아니요 |
| Agent Review Status | `agent-review-<PR number>` | 아니요 |
| Deploy | `deploy-<stage>` | 아니요 |

에이전트 workflow는 절대 취소되지 않습니다. 각 실행은 자신의 시도를 정확히 한 번 세거나 issue를 정확히 한 번 열어야 하며,
PR별 그룹이므로 서로 관련 없는 PR이 서로를 기다리지 않습니다.

## 실행하는 Nx target

모두 `@your-scope/common-scripts`에 있습니다.

| Target | Entry point | 읽는 환경 변수 |
| --- | --- | --- |
| `agent-issue` | `src/agent-issues/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_NAME`, `GITHUB_EVENT_PATH`, `SPEC_FOLDER`, `DRY_RUN` |
| `archive-specs` | `src/agent-issues/archive-main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_WORKSPACE`, `BASE_BRANCH`, `DRY_RUN` |
| `agent-ci-status` | `src/agent-ci/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_PATH`, `DRY_RUN` |
| `agent-review-status` | `src/agent-review/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_PATH`, `DRY_RUN` |
| `ui-screenshots` | `src/ui-screenshots/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_PATH` |
| `validate-tasks` | `src/agent-issues/validate-main.ts` | `GITHUB_WORKSPACE`, `GITHUB_ACTIONS` (annotation용) |
