<CardGrid>
  <Card title="Um ambiente em que você pode confiar" icon="approve-check">
    Regras, testes e checks são organizados em camadas para que um erro venha à tona e volte para o agent, não para você.
  </Card>
  <Card title="Escreva a spec" icon="pencil">
    Toda feature começa como uma spec, um plano e uma lista de tarefas revisados. O agent constrói a partir deles, não a partir de um chat.
  </Card>
  <Card title="Os agents fazem o resto" icon="rocket">
    Uma spec mergeada abre uma issue por fase. Um agent abre o PR e corrige CI vermelho ou feedback de review sozinho, até cinco vezes por loop.
  </Card>
  <Card title="Você dá a direção" icon="information">
    Pessoas aprovam a spec e têm a palavra final antes do merge. Tudo o que fica no meio roda sozinho.
  </Card>
</CardGrid>
