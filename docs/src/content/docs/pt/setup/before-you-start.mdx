Um [fork deste repositório](../../guides/fork-this-repo/) tem tudo o que o setup do Discava mantém
no repositório. Estes passos adicionam a parte que fica fora dele: as configurações do GitHub, um
GitHub App com que os agents agem e uma instalação do OpenHands apontada para o seu fork. Depois
você escreve uma spec para o app de notas e acompanha o caminho dela, do PR de spec até os PRs dos
agents mergeados.

**Tempo:** cerca de uma hora, a maior parte esperando a primeira execução do agent.

## O que você precisa

No macOS ou no Linux (no Windows, use o WSL):

| Item | Por quê |
| --- | --- |
| Uma conta no GitHub | Para fazer o fork, escrever specs e revisar |
| GitHub CLI (`gh`), com login feito | O script de configuração e os agents usam ele |
| Node.js 24 e pnpm | Para rodar o repositório e o Agent Canvas |
| `uv` | O Agent Canvas inicia o backend com `uvx` |
| Um coding agent, instalado e com login feito | Ele escreve specs com o Speckit e faz o trabalho dos agents dentro do OpenHands. O Discava usa o Claude Code |
| Docker (opcional) | Só para rodar o app de notas e os testes e2e na sua máquina. O CI roda eles para os agents |

<Aside type="note">
O Agent Canvas roda na sua própria máquina e consulta o GitHub periodicamente, então não precisa de
endereço público nem de webhook. Os agents só trabalham enquanto ele está rodando.
</Aside>

## Os passos

| # | Passo | O que você faz | No final você terá |
| --- | --- | --- | --- |
| 1 | [Faça um fork do repositório](../fork/) | Três comandos | Sua própria cópia, clonada |
| 2 | [Configure o repositório](../github-repository/) | Cria um GitHub App a partir de um formulário já preenchido, roda um script | O GitHub App dos agents no seu fork, os labels, uma `main` protegida, comentários limitados a colaboradores |
| 3 | [Instale o OpenHands](../openhands/) | Dois comandos, dois perfis na interface web | O Agent Canvas rodando como o seu app, com um perfil `developer` e um perfil `reviewer` |
| 4 | [Crie as duas automações](../automations/) | Dois formulários na interface web, um prompt para colar | Os agents Desenvolvedor e Revisor implementando e revisando no seu fork |
| 5 | [Rode sua primeira feature](../first-feature/) | Escreve uma spec, revisa pull requests | Uma spec para o app de notas, levada até código mergeado pelos agents |
