**No final você terá:** seu próprio fork, clonado localmente, com os checks passando.

<Steps>

1. **Faça o fork e clone.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Torne seu fork o padrão do `gh`.** Caso contrário, os comandos `gh` apontam para o repositório
   original, não para o seu.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Instale e rode os checks localmente**, os mesmos que o CI roda:

   ```bash
   pnpm install
   pnpm nx run-many --target lint --all
   pnpm nx run-many --target test --all
   pnpm nx run-many --target build --all
   ```

   O `pnpm install` também instala os git hooks: Conventional Commits em toda mensagem de commit,
   um scan de secrets e o Biome antes de todo commit, e uma checagem do mapa de invariantes antes de
   todo push. Para rodar o app de notas (precisa de Docker): `pnpm dev`, depois abra a URL que o site imprime.

</Steps>

## Confira se funcionou

Os três comandos `nx run-many` passam, e um commit cuja mensagem não é um Conventional Commit é
recusado:

```bash
git commit --allow-empty -m "not conventional"
```

```text
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

O GitHub desliga Issues e Actions em um fork. O script do próximo passo os liga de novo.

<Aside type="note">
Sem o secret `CODECOV_TOKEN`, o passo de upload de cobertura do CI registra um erro e segue em frente.
Adicione o secret, ou apague o passo, se quiser silêncio.
</Aside>
