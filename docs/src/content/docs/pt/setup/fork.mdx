**No final você terá:** seu próprio fork, clonado localmente, pronto para o script de configuração.

<Steps>

1. **Faça o fork e clone.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Torne seu fork o padrão do `gh`.** Caso contrário, os comandos `gh`, e os pull requests que
   você abre com ele, apontam para o repositório original, não para o seu.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Instale as dependências.**

   ```bash
   pnpm install
   ```

   Isso também instala os git hooks que você vai encontrar quando fizer o commit da sua primeira
   spec: Conventional Commits em toda mensagem de commit, e um scan de secrets e o Biome antes de
   todo commit.

</Steps>

## Confira se funcionou

```bash
gh repo set-default --view
```

imprime `<you>/agentic-sdlc`.

O GitHub desliga Issues e Actions em um fork. O script do próximo passo os liga de novo.

<Aside type="tip" title="Opcional: veja rodando">
Para rodar o que o CI roda (lint, testes e build): `pnpm build`. Para rodar o app de notas (precisa
de Docker): `pnpm dev`, depois abra a URL que o site imprime. Nenhum dos dois é necessário para a
configuração: o CI roda os checks em todo pull request.
</Aside>

<Aside type="note">
Sem o secret `CODECOV_TOKEN`, o passo de upload de cobertura do CI registra um erro e segue em frente.
Adicione o secret, ou apague o passo, se quiser silêncio.
</Aside>
