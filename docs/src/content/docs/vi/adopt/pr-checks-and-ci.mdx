**Kết quả:** một workflow **PR Checks** mà thất bại của nó cấp dữ liệu cho vòng CI, một check **UI
Screenshots**, và **CI** trên `main`.

<Steps>

1. **Chép bốn workflow** từ `.github/workflows/` của repository này:

   | File | Nó làm gì |
   | --- | --- |
   | `pr-checks.yml` | Lint, test và build những gì PR ảnh hưởng; `Tasks format`; `Invariant coverage`; e2e chia shard, gom lại thành một check `E2E tests`; comment `E2E screenshots` |
   | `ui-screenshots.yml` | Quy tắc ảnh chụp màn hình, như một workflow riêng, để thêm hoặc gỡ label `no-ui-screenshots` chỉ chạy lại check này. Discava thì chạy nó như một job của PR Checks. Cách nào cũng được |
   | `ci.yml` | Cùng các check trên mọi lần push lên `main`, Trivy, cache Playwright, và deploy trang docs này |
   | `cache-cleanup.yml` | Xóa cache của một PR khi PR đó đóng |

   Giữ chính xác `name: PR Checks` của `pr-checks.yml`: Agent CI Status lắng nghe một workflow có
   tên đó.

2. **Trỏ chúng vào các project của bạn.** Tìm `@agentic-sdlc/` trong các file đã chép và đổi scope.
   Sau đó, trong `pr-checks.yml`:

   | Job | Thay đổi |
   | --- | --- |
   | `invariant-coverage` | Các `paths` của code có thể ghi vào bảng của bạn, giống như `WRITER_PACKAGES` ở bước 5. Hoặc xóa job này nếu bạn chưa kiểm tra invariant |
   | `e2e` | Số shard trong `matrix.shard`, cho hợp với bộ test của bạn. Mỗi shard tốn khoảng hai phút trước test đầu tiên, nên ngừng thêm khi test của mỗi shard chỉ mất chừng ấy thời gian |
   | `e2e-screenshots` | Không gì cả, khi [bước 8](../local-stack-and-e2e/) đã xong |

   Trong `ci.yml`, xóa job `deploy_docs` và permission `pages: write` của nó, trừ khi bạn publish
   một trang docs từ `docs/`.

3. **Giữ những gì giúp agent nhanh.** Bước `Check for mutations` trong `ci.yml` (`git diff
   --exit-code` sau khi build) bắt các file sinh ra mà agent quên commit. Job `playwright-cache` lưu
   Chromium từ `main`, vì các lần chạy PR chỉ có thể khôi phục cache được lưu ở đó. Job `build` lưu
   task cache của Nx từ `main`, để lần chạy đầu tiên của một PR phát lại những gì `main` đã build, và
   agent chờ ít hơn ở mỗi vòng fix-up. Mỗi leg `checks` trong PR Checks giữ cache riêng theo cách
   tương tự, trừ `lint`, vốn chỉ khôi phục. `init-monorepo` giới hạn cache ở 1 GB, và Cache Cleanup
   giải phóng phần của một PR đã đóng trong 10 GB của repository. Xem
   [Giữ cho nhanh](../../discava/pr-checks/#giữ-cho-nhanh) để biết việc này đã giúp Discava những gì.

</Steps>

Mọi action đều được ghim vào một commit SHA, và `dependabot.yml` bạn đã chép ở bước 1 giữ các pin
luôn cập nhật.

## Kiểm tra kết quả

Mở một PR dùng thử làm hỏng một dòng `tasks.md`, ví dụ bằng cách thụt lề một task. Check **Tasks
format** thất bại với một annotation trên dòng đó:

```text
A task must be written "- [ ] T<3 digits> <description>", starting in the first column
```

Mở một PR khác thay đổi một file UI mà không chạm vào kịch bản nào. **UI Screenshots** thất bại:

```text
This pull request changes UI source (…) but no e2e scenario gained a `screenshot(page, 'name')` call.
```

<Aside type="note">
`codecov/codecov-action` trong các file đã chép cần một secret `CODECOV_TOKEN`. Gỡ bước đó nếu bạn
không dùng Codecov.
</Aside>
