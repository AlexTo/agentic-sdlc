**Kết quả:** `.specify/` trong repository, các lệnh `speckit-*` có sẵn cho coding agent của bạn, và
thư mục spec được đặt tên theo timestamp.

<Steps>

1. **Cài CLI**, ghim vào phiên bản Discava dùng:

   ```bash
   uv tool install specify-cli --from "git+https://github.com/github/spec-kit.git@v1.3.2"
   specify --version
   ```

   ```text
   specify 1.3.2
   ```

2. **Chép `.specify/`** từ repository này. Nó đã được thiết lập đúng như quy trình cần:

   | Thiết lập | Ở đâu | Giá trị |
   | --- | --- | --- |
   | Thư mục spec đặt tên theo timestamp | `extensions/git/git-config.yml` | `branch_numbering: timestamp`, nên hai người viết spec cùng lúc không bao giờ trùng: `specs/20261116-013307-course-reviews/`, không phải `specs/001-course-reviews/` |
   | Conventional commit cho mỗi bước | `extensions/git/git-config.yml` | `commit_style: conventional` |
   | Các hook của extension git chạy mà không hỏi | `extensions.yml` | `auto_execute_hooks: true`: một nhánh trước `/speckit-specify`, một commit sau mỗi bước |
   | Các template và constitution | `templates/`, `memory/` | Đã mang sẵn các thay đổi ở [bước 3](../constitution-and-templates/) |

3. **Thêm các lệnh cho coding agent của bạn.** Nếu nó đọc skill của Claude Code, hãy chép
   `.claude/skills/speckit-*` từ repository này. Nếu không, để Speckit viết chúng cho agent của bạn
   trong một thư mục nháp, và chỉ chép các file lệnh:

   ```bash
   mkdir /tmp/speckit && cd /tmp/speckit
   specify init --here --integration <your-agent> --script sh --extension git
   ```

   Chạy `specify init --help` để xem danh sách tích hợp. Chép thư mục nó tạo cho các lệnh của agent,
   không chép `.specify/` của nó, vì như vậy sẽ hoàn tác bước 2.

4. **Commit `.specify/`** và các file lệnh hoặc skill.

</Steps>

## Kiểm tra kết quả

<FileTree>
- .specify/
  - extensions/git/ git-config.yml, lệnh, script
  - extensions.yml
  - init-options.json
  - memory/constitution.md của ứng dụng ghi chú, được viết lại cho project của bạn ở bước tiếp theo
  - scripts/bash/
  - templates/ template spec, plan, tasks, checklist và constitution
</FileTree>

Trong coding agent của bạn, các lệnh `speckit-specify`, `speckit-clarify`, `speckit-plan`,
`speckit-tasks`, `speckit-analyze` và `speckit-constitution` được liệt kê.

<Aside type="tip">
Spec PR đi trên nhánh riêng (`spec/<name>`), không phải `openhands/...`. Nhánh tính năng của extension
git dùng tốt cho việc đó. Chỉ nhánh của agent mới dùng tiền tố `openhands/`.
</Aside>
