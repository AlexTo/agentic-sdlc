import { Steps, Aside, FileTree } from '@astrojs/starlight/components';

**Kết quả:** `.specify/` trong repository, các lệnh `speckit-*` có sẵn cho coding agent của bạn, và
thư mục spec được đặt tên theo timestamp.

<Steps>

1. **Cài CLI**, ghim vào phiên bản Discava dùng:

   ```bash
   uv tool install specify-cli --from "git+https://github.com/github/spec-kit.git@v1.3.2"
   specify --version
   ```

   ```text
   specify 1.3.2
   ```

2. **Khởi tạo nó trong repository** cho coding agent của bạn, với extension git đi kèm. Discava dùng
   tích hợp `claude`, cài các lệnh dưới dạng skill:

   ```bash
   specify init --here --integration claude --script sh --extension git
   ```

   Chạy `specify init --help` để xem các tích hợp khác. Chọn cái mà agent của team bạn đọc.

3. **Chuyển sang đánh số theo timestamp.** Trong `.specify/extensions/git/git-config.yml`:

   ```yaml
   branch_numbering: timestamp
   commit_style: conventional
   ```

   Thư mục trở thành `specs/20261116-013307-course-reviews/` thay vì `specs/001-course-reviews/`, nên
   hai người viết spec cùng lúc không bao giờ trùng số.

4. **Kiểm tra các hook của extension git** trong `.specify/extensions.yml`. Discava giữ mặc định:
   `speckit.git.feature` trước `/speckit-specify` (tạo nhánh), và `speckit.git.commit` sau mỗi bước
   (mỗi bước một commit). Nó đặt `auto_execute_hooks: true` để chúng chạy mà không hỏi.

5. **Commit `.specify/`** và các file lệnh hoặc skill của tích hợp.

</Steps>

## Kiểm tra kết quả

<FileTree>
- .specify/
  - extensions/git/ git-config.yml, lệnh, script
  - extensions.yml
  - init-options.json
  - memory/constitution.md vẫn là template, được điền ở bước tiếp theo
  - scripts/bash/
  - templates/ template spec, plan, tasks, checklist và constitution
</FileTree>

Trong coding agent của bạn, các lệnh `speckit-specify`, `speckit-clarify`, `speckit-plan`,
`speckit-tasks`, `speckit-analyze` và `speckit-constitution` được liệt kê.

<Aside type="tip">
Spec PR đi trên nhánh riêng (`spec/<name>`), không phải `openhands/...`. Nhánh tính năng của extension
git dùng tốt cho việc đó. Chỉ nhánh của agent mới dùng tiền tố `openhands/`.
</Aside>
