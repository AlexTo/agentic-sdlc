**Kết quả:** một pnpm workspace với Nx, Biome, Conventional Commits được thực thi trên mọi commit, và
một bước kiểm tra secret trước mọi commit.

Glue không cần Nx. Nhưng `nx affected` là thứ giữ cho PR check đủ nhanh để agent lặp lại, và mọi script
glue chạy như một Nx target. Nếu bạn dùng công cụ monorepo khác, hãy giữ ý tưởng: chỉ chạy những gì PR
ảnh hưởng, và expose mọi script thành một task có tên.

<Steps>

1. **Tạo workspace**, nếu bạn chưa có. Cả Discava và repository này đều được tạo bằng Nx Plugin for
   AWS:

   ```bash
   pnpm create @aws/nx-workspace your-project --iac=cdk --no-interactive
   ```

   Một Nx workspace có sẵn cũng được. Ghim pnpm trong `package.json` ở gốc bằng `packageManager`,
   để CI và agent dùng cùng phiên bản.

2. **Chép các file này** từ repository này sang cùng đường dẫn trong repository của bạn:

   <FileTree>
   - commitlint.config.js Conventional Commits
   - lint-staged.config.js Biome trên các file đã stage
   - .husky/
     - commit-msg chạy commitlint
     - pre-commit git-secrets, rồi lint-staged, và thất bại nếu Biome thay đổi gì, để agent stage lại và commit lần nữa
     - prepare-commit-msg Commitizen, cho những người commit tương tác. Nó tự bỏ qua với `git commit -m`, cách agent commit
   - .git-secrets/ script git-secrets mà hook pre-commit chạy
   - .gitallowed các pattern mà git-secrets cho qua
   - .github/
     - actions/init-monorepo/ thiết lập CI dùng chung
     - actions/changed-paths/ "PR này có thay đổi đường dẫn nào trong số này không?", để bỏ qua job
     - actions/playwright-setup/ Chromium cho Playwright, cache theo phiên bản
     - dependabot.yml giữ các action và dependency đã ghim luôn cập nhật
   </FileTree>

   Để `.husky/pre-push` lại cho đến [bước 8](../local-stack-and-e2e/): nó kiểm tra bản đồ invariant.
   `init-monorepo` cài pnpm (thử ba lần, vì một timeout của registry sẽ khiến agent mất một lượt
   fix-up), Node 24 và tùy chọn uv, khôi phục cache pnpm và Nx, cài dependency, và đặt
   `NX_BASE`/`NX_HEAD` cho `nx affected`.

3. **Chép các script ở gốc và dev dependency** từ `package.json` của repository này: khối `scripts`
   (mà `AGENTS.md`, CI và agent gọi), và từ `devDependencies`, `@commitlint/config-conventional`,
   `commitlint`, `commitizen`, `husky` và `lint-staged`. Rồi:

   ```bash
   pnpm install
   ```

   Script `prepare` của nó cài các hook.

4. **Đổi package scope** trong `.github/actions/playwright-setup/action.yml`
   (`@agentic-sdlc/e2e`) thành tên project e2e của bạn.

</Steps>

## Kiểm tra kết quả

```bash
git commit --allow-empty -m "not conventional"
```

```text
⧗   input: not conventional
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

Sau đó `git commit --allow-empty -m "chore: check hooks"` thành công.

<Aside type="note">
Tiêu đề issue mà glue viết là header Conventional Commit, và agent dùng lại chúng cho commit và pull
request của nó. Đó là lý do commitlint đi đầu tiên.
</Aside>
