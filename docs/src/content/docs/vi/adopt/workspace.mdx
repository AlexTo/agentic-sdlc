**Kết quả:** một pnpm workspace với Nx, Biome, Conventional Commits được thực thi trên mọi commit, và
một bước kiểm tra secret trước mọi commit.

Glue không cần Nx. Nhưng `nx affected` là thứ giữ cho PR check đủ nhanh để agent lặp lại, và mọi script
glue chạy như một Nx target. Nếu bạn dùng công cụ monorepo khác, hãy giữ ý tưởng: chỉ chạy những gì PR
ảnh hưởng, và expose mọi script thành một task có tên.

<Steps>

1. **Tạo workspace**, nếu bạn chưa có. Cả Discava và repository này đều được tạo bằng Nx Plugin for
   AWS:

   ```bash
   pnpm create @aws/nx-workspace your-project --iac=cdk --no-interactive
   ```

   Lệnh này cũng cài hook pre-commit git-secrets được dùng ở bước con 4. Một Nx workspace có sẵn cũng
   được. Ghim pnpm trong `package.json` ở gốc, để CI và agent dùng cùng phiên bản:

   ```json
   { "packageManager": "pnpm@<version>" }
   ```

2. **Thêm các script ở gốc** mà `AGENTS.md`, CI và agent sẽ gọi:

   ```json
   "scripts": {
     "dev": "nx run-many --target dev",
     "build": "nx run-many --target build",
     "lint": "nx run-many --target lint --configuration=fix",
     "test": "nx run-many --target test --all",
     "trivy": "nx run-many --target trivy --all",
     "prepare": "husky"
   }
   ```

3. **Thêm Conventional Commits với commitlint.** Tiêu đề issue mà glue viết là header Conventional
   Commit, và agent dùng lại chúng.

   ```bash
   pnpm add -Dw @commitlint/config-conventional commitlint husky lint-staged
   echo "export default { extends: ['@commitlint/config-conventional'] };" > commitlint.config.js
   ```

   `.husky/commit-msg`:

   ```bash
   FORCE_COLOR=1 pnpm commitlint --edit "$1"
   ```

4. **Thêm hook pre-commit.** Nó đăng ký các pattern secret AWS một lần, từ chối commit chứa secret,
   chạy Biome trên các file đã stage, và thất bại nếu việc đó thay đổi gì, để agent stage lại và commit
   lần nữa. `.husky/pre-commit`:

   ```bash
   if ! git config --get-all secrets.patterns >/dev/null 2>&1; then
     bash .git-secrets/git-secrets --register-aws
   fi
   bash .git-secrets/git-secrets --pre_commit_hook

   PRE_SHA="$(git diff HEAD --ignore-space-at-eol | shasum -a 256 --tag)"
   FORCE_COLOR=1 pnpm lint-staged
   POST_SHA="$(git diff HEAD --ignore-space-at-eol | shasum -a 256 --tag)"

   if [ "$PRE_SHA" != "$POST_SHA" ]; then
     echo "Pre-commit modified your working directory"
     echo "Please verify and stage changed, then retry git commit"
     exit 1
   fi
   ```

   Một workspace từ Nx Plugin for AWS đã có `.git-secrets/git-secrets`, `.gitallowed` và phần lớn hook
   này. Nếu không, hãy chép chúng từ repository này. `lint-staged.config.js`:

   ```js
   export default {
     'packages/**/*.{ts,tsx,js,jsx,json,css,scss}': ['biome check --write --no-errors-on-unmatched'],
     '*.{js,json}': ['biome check --write --no-errors-on-unmatched'],
   };
   ```

5. **Chép action thiết lập CI dùng chung** từ repository này: `.github/actions/init-monorepo/`. Nó cài
   pnpm (thử ba lần, vì một timeout của registry sẽ khiến agent mất một lượt fix-up), Node 24 và tùy
   chọn uv, khôi phục cache pnpm, cài dependency, và đặt `NX_BASE`/`NX_HEAD` cho `nx affected`.

</Steps>

## Kiểm tra kết quả

```bash
git commit --allow-empty -m "not conventional"
```

```text
⧗   input: not conventional
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

Sau đó `git commit --allow-empty -m "chore: check hooks"` thành công.

<Aside type="note">
Discava cũng chạy Commitizen từ `prepare-commit-msg` cho những người commit tương tác. Nó tự bỏ qua khi
message được đưa bằng `-m`, cách agent commit, nên nó là tùy chọn.
</Aside>
