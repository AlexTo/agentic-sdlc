[Discava](https://github.com/AlexTo/discava) là một hệ thống quản lý học tập serverless trên AWS: ba
cổng React, ba tRPC API trên Lambda, một bảng DynamoDB duy nhất, một pipeline media và tìm kiếm, được
deploy bằng CDK từ một Nx monorepo. Nó đủ lớn để không ai nắm hết trong đầu, và đó chính là lúc quy
trình phát huy giá trị.

Phần này mô tả những gì Discava chạy, tính đến tháng 11 năm 2026, cùng các file đứng sau mỗi phần.

## Công cụ và phiên bản

| Công cụ | Phiên bản | Vai trò |
| --- | --- | --- |
| Speckit (`specify-cli`) | 1.3.2 | Sinh spec, kế hoạch và task, với extension `git` |
| OpenHands Agent Canvas | 1.45.0 | Runtime của agent và ba automation, như một user service trên một máy Linux |
| GitHub App `alex-coding-agent` | | Danh tính mà các agent dùng trên GitHub, với token có hiệu lực một giờ |
| Automation `github-issue-to-pr` | 1.2.4 | Developer: triển khai issue có label, sửa lại PR thất bại |
| Automation `github-pr-reviewer` | 1.11.2, đã vá | Reviewer: review PR khi các check đã xong |
| Automation `github-issue-tester` | viết tay | Tester: test các PR đã merge trên stage development đã deploy |
| Agent Developer | Claude Code qua ACP, Sonnet | Agent profile `developer` |
| Agent Reviewer | Claude Code qua ACP, Opus | Agent profile `reviewer` |
| Agent Tester | Claude Code qua ACP, Opus | Agent profile `tester` |
| Nx + pnpm | Nx 23 | Monorepo, `nx affected` trong CI |
| Playwright | | E2E test trên local stack, mười hai shard trong CI. Agent Tester cũng dùng nó để điều khiển các cổng đã deploy |
| Trivy, git-secrets, commitlint | | Quét bảo mật, kiểm tra secret trước commit, định dạng commit message |

## Từ khoảng trống đến file

| Khoảng trống | Câu trả lời của Discava | File |
| --- | --- | --- |
| Spec sang issue | Workflow Agent Issues và các script của nó | `.github/workflows/agent-issues.yml`, `packages/tooling/agent/src/agent-issues/` |
| CI thất bại sang agent | Agent CI Status | `.github/workflows/agent-ci.yml`, `src/agent-ci/` |
| Review sang agent | Agent Review Status | `.github/workflows/agent-review.yml`, `src/agent-review/` |
| Vòng lặp vô tận | Giới hạn năm lượt thử với label | `MAX_CI_FIX_ATTEMPTS` và `MAX_REVIEW_FIX_ATTEMPTS` trong `plan.ts` |
| `tasks.md` sai định dạng | Job Tasks format | `pr-checks.yml` `tasks-format`, `src/agent-issues/validate.ts` |
| Thay đổi UI chưa ai xem | Job UI Screenshots, comment E2E screenshots | `pr-checks.yml`, `src/ui-screenshots/`, `packages/e2e/src/helpers/screenshots.ts` |
| Merge không tiếp tục chuỗi | Agent Issues trên các nhánh `openhands/` đã merge | `src/agent-issues/gate.ts` |
| Agent không có cloud | Bản thay thế local cho mọi dịch vụ AWS | `pnpm dev`, `packages/tooling/local-dev/src/{dynamodb,s3mock,elasticmq,opensearch,local-oidc}` |
| Merge không ship | CI trên `main`, rồi Deploy | `.github/workflows/ci.yml`, `deploy.yml`, `scripts/setup-stage.sh` |
| Secret và dependency có lỗ hổng | Trivy trong CI và trước deploy, git-secrets khi commit | `ci.yml` `trivy`, `deploy.yml`, `.husky/pre-commit`, `.trivyignore` |
| Thay đổi đã merge không bao giờ được test ở nơi nó chạy | Post-merge Verify mở một issue test cho mỗi PR đã deploy, agent Tester test nó, và chỉ các collaborator mới comment được trên những gì các agent đọc | `.github/workflows/post-merge-verify.yml`, `src/post-merge-test/`, `src/helpers/conversation-lock.ts`, interaction limit của repository |

Phần glue nằm trong `packages/tooling/agent/` (`@discava/tooling-agent`). Các đường dẫn `src/…` trong
phần này là tương đối so với nó.

Và văn bản hướng dẫn mà mọi agent đọc:

| Hướng dẫn | File |
| --- | --- |
| Quy tắc dự án, được mọi kế hoạch kiểm tra | `.specify/memory/constitution.md` (phiên bản 1.2.1) |
| Lệnh, kiến trúc, quy ước | `AGENTS.md` |
| Quy trình PR, local stack, testing | `DEVELOPMENT.md` |
| Không nhận issue hay pull request từ bên ngoài; ý tưởng và báo lỗi gửi vào Discussions | `CONTRIBUTING.md` |
| Hướng dẫn trên mọi issue triển khai | `.github/ISSUE_TEMPLATE/implement-phase.md` |
| Dạng mở thủ công của một issue test | `.github/ISSUE_TEMPLATE/test-deployed-pr.md` |
| Prompt cố định của mỗi vai trò agent | Trong OpenHands, bên ngoài repository. Xem [Prompt của các agent](../agent-prompts/) |
| Template Speckit, tùy biến cho automation | `.specify/templates/tasks-template.md`, `spec-template.md` |

## Qua các con số

Từ ngày 14 tháng 11, khi quy trình bắt đầu chạy thật, đến ngày 24 tháng 11 năm 2026:

- 29 spec tính năng được viết bằng Speckit, trong `specs/`.
- 9.869 lượt quét automation, lúc đầu cứ năm phút một lần và cứ hai phút một lần từ ngày 22 tháng
  11: 3.932 lần poll issue-to-PR, 3.670 lần poll review và 2.267 lần poll kiểm thử. 603 lượt trong
  số đó tìm thấy việc và khởi động một agent.
- 263 agent PR được merge. 95 không cần sửa tự động, 81 cần một vòng, hai PR làm cạn một vòng lặp.
