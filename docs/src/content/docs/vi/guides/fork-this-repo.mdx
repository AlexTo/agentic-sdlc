Repository này *chính là* quy trình: cùng thiết lập Speckit, issue template, PR check, agent
workflow và phần glue có unit test mà Discava đang chạy, bao quanh một ứng dụng ghi chú nhỏ.

**Fork nó, và bạn có thiết lập của Discava.** Trỏ OpenHands của chính bạn vào bản fork, viết một
spec cho ứng dụng ghi chú, và spec đó đi qua vòng lặp được mô tả trong
[Cách hoạt động](../how-it-works/).

## Bạn nhận được gì

<FileTree>
- AGENTS.md thứ mọi agent đọc đầu tiên, viết cho ứng dụng ghi chú
- .specify/ template, script của Speckit và constitution
- .husky/ Conventional Commits, quét secret và Biome khi commit, bản đồ invariant khi push
- scripts/
  - setup-repository.sh các label, branch protection và những thiết lập khác mà fork không sao chép
  - start-agent-canvas.mjs khởi động Agent Canvas dưới danh nghĩa GitHub App của các agent và giữ token của nó luôn mới
- .github/
  - ISSUE_TEMPLATE/
    - implement-phase.md hướng dẫn mà mọi issue triển khai đều mang theo
    - test-deployed-pr.md một issue test cho agent Tester, tạo bằng tay
  - actions/ thiết lập CI dùng chung, Chromium của Playwright, check đường dẫn thay đổi
  - dependabot.yml giữ các action và dependency đã ghim luôn cập nhật
  - workflows/
    - pr-checks.yml lint, test, build, định dạng tasks, invariant coverage, e2e, comment ảnh chụp màn hình
    - ui-screenshots.yml quy tắc ảnh chụp màn hình
    - ci.yml check, Trivy và deploy docs trên main
    - agent-issues.yml spec → issue, merge → issue tiếp theo
    - archive-specs.yml spec đã xong → PR lưu trữ
    - agent-ci.yml CI đỏ → agent
    - agent-review.yml "changes requested" → agent
    - agent-status.yml các bước mà hai workflow trên dùng chung
    - deploy.yml main xanh → một stage, tắt cho đến khi bạn thêm hạ tầng
    - post-merge-verify.yml PR đã deploy → issue test cho Tester
    - cache-cleanup.yml cache của một PR đã đóng
- packages/
  - tooling/agent/ các quy tắc của glue, với 223 unit test
  - tooling/local-dev/ khởi động DynamoDB local cho `pnpm dev`
  - notes-table/ entity ElectroDB, DynamoDB local, invariant
  - notes-api/ các procedure tRPC
  - notes-website/ React, Vite, TanStack Router, shadcn/ui
  - e2e/ kịch bản Playwright, helper `screenshot()`, invariant sau mọi test
- docs/ trang web này
</FileTree>

Ứng dụng ghi chú chạy hoàn toàn ở máy local (`pnpm dev`, với Docker cho DynamoDB local), nên CI có
thể chạy e2e test của nó và agent không bao giờ cần thông tin đăng nhập cloud.

## Bạn cần thêm gì

Chỉ những thứ không thể nằm trong repository:

1. **Thiết lập GitHub**: GitHub App mà các agent hoạt động dưới danh nghĩa của nó, và các thiết lập
   mà fork không sao chép, được `scripts/setup-repository.sh` đặt trong một lần chạy.
2. **OpenHands**: Agent Canvas trên máy bạn, được khởi động dưới danh nghĩa app bằng
   `pnpm agent-canvas`, và các automation trỏ vào bản fork của bạn.

## Những gì tắt cho đến khi bạn thêm vào

Cloud. Ứng dụng ghi chú không có hạ tầng cloud, nên merge không ship gì ngoài trang docs.
`deploy.yml` và `post-merge-verify.yml` đã có sẵn nhưng không bao giờ tự chạy: thêm một CDK app tại
`packages/infra` và đặt `AUTO_DEPLOY_STAGE`, rồi mọi `main` xanh đều được deploy, sau đó agent
Tester test những gì đã được deploy. [Áp dụng: deploy](../../adopt/deploy/) có các bước, và
[Deploy và bảo mật](../../discava/deploy-and-security/) mô tả pipeline của Discava.
