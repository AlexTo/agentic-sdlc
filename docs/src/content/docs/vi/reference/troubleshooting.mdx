## Chuỗi không bắt đầu hoặc không tiếp tục

| Triệu chứng | Chuyện gì đang xảy ra | Cần làm gì |
| --- | --- | --- |
| Spec PR đã merge, không có issue | PR không có label `spec-ready` khi được merge | Thêm `spec-ready` vào PR đã merge. Agent Issues cũng chạy khi `labeled` |
| Agent Issues đã chạy: `No issue created: it is not an agent branch and has no "spec-ready" label` | Như trên, hoặc PR là PR của người, vốn bị bỏ qua theo thiết kế | Như trên, hoặc chạy Agent Issues thủ công với thư mục spec |
| Agent Issues thất bại: `tasks.md is not in the format the workflow reads` | Kiểm tra định dạng đã bị bỏ qua hoặc phớt lờ trên spec PR | Sửa `tasks.md` trong một PR, rồi chạy Agent Issues thủ công |
| Một comment: "the next implementation issue … was not opened: an issue for … already exists" | Issue của giai đoạn đã tồn tại, nhưng một số task agent trong đó chưa được đánh dấu | Đánh dấu nếu đã xong, hoặc hoàn thành chúng. Rồi chạy Agent Issues thủ công |
| Agent Issues log `no spec folder with a tasks.md was found` | Issue của agent PR đã merge không có marker, và PR không thay đổi file `specs/` nào | Chạy Agent Issues thủ công với thư mục spec |
| Giai đoạn cuối đã merge và không có gì mở | Đúng. Các task còn lại chỉ là **(human)** hoặc không còn task nào | Xong |

## Agent không nhận việc hoặc không sửa lại

| Triệu chứng | Chuyện gì đang xảy ra | Cần làm gì |
| --- | --- | --- |
| Issue có label không bao giờ được nhận | Agent Canvas đang tắt, automation bị vô hiệu, hoặc token không đọc được repository | Kiểm tra `agent-canvas` đang chạy và automation đã bật. Xem log lần chạy cuối của automation |
| PR đỏ, đã thêm `ci-fix-1`, agent không bao giờ sửa lại | Worker chỉ sửa lại đúng `openhands/issue-<n>` (các workflow fix-up cũng gắn label cho các nhánh `openhands/` khác), hoặc issue đã bị đóng | Kiểm tra tên nhánh. Mở lại issue, hoặc tự tiếp quản PR |
| Không có label `ci-fix-*` sau một lần chạy đỏ | Agent CI Status không chạy, hoặc đã bỏ qua nó (xem notice) | Mở lần chạy Agent CI Status và đọc notice, ví dụ `the pull request has a newer commit than this run` |
| Agent sửa lại, rồi không có gì review head mới | Agent không gắn lại `openhands-review` | Gắn lại thủ công |
| Push bị từ chối: `refusing to allow a GitHub App to create or update workflow` | App thiếu quyền ghi **Workflows**, và nhánh chạm vào `.github/workflows/` (thường qua một lần merge `main`) | Cấp quyền đó trong thiết lập của app, và chấp nhận quyền mới trên installation. Lần poll kế sẽ thử lại. Với personal access token, thông báo nêu tên loại token đó, và token cần scope `workflow` |
| Mọi automation đều thất bại: `The GitHub credential GITHUB_PERSONAL_ACCESS_TOKEN is unavailable`, hoặc `401 Bad credentials` | Secret bị thiếu, hoặc đang giữ một token của app đã quá một giờ | Khởi động Agent Canvas bằng `pnpm agent-canvas` và để nó chạy: nó thay token mỗi 45 phút, và log mỗi token nó lưu. Đang chạy Agent Canvas như một service? Kiểm tra timer chạy `pnpm agent-canvas --once` |
| `ci-fix-exhausted` | Năm lượt fix-up không hội tụ | Đọc lần thất bại cuối. Thường là spec hoặc kế hoạch mơ hồ. Sửa nó, gỡ các label, chạy lại |

## Review

| Triệu chứng | Chuyện gì đang xảy ra | Cần làm gì |
| --- | --- | --- |
| "⏳ Review waiting on checks" và không có review | Một check trên head chưa xong, hoặc bị kẹt trong hàng đợi | Tìm check đang chờ. Một required check không bao giờ chạy sẽ chặn review mãi mãi |
| Review nói `🔄 CHANGES REQUESTED`, không có label `review-fix-*` | Review thiếu marker lần chạy, không đến từ tài khoản có quyền ghi hay app có tên trong `AGENT_APP_LOGIN`, hoặc PR đã đi tiếp | Đọc notice của Agent Review Status. Nếu nó nói review không đến từ maintainer hay app của agent, hãy đặt biến repository `AGENT_APP_LOGIN` bằng bot login của app |
| Mọi lần quét code review đều thất bại với `HTTP Error 403: Forbidden` | Template `github-pr-reviewer` hỏi `GET /user` xem nó là ai, và GitHub từ chối installation token của app ở đó (`Resource not accessible by integration`) | Để một agent vá bundle của automation, bằng prompt trong [Tạo hai automation, bước 3](../../setup/automations/). Bản vá: ở chỗ worker đọc login từ `GET /user` (`github_login` trong `worker.py`, phần kiểm tra token trong `main.py`), khi gặp 403 thì chuyển sang GraphQL `{ viewer { login } }`, vốn trả về `<app-name>[bot]` |
| Review hiện là "Commented", không phải "Approved" | Reviewer đăng bằng cùng danh tính đã mở PR, và GitHub không cho tự duyệt | Bình thường: Developer và Reviewer dùng chung GitHub App của các agent. Glue đọc dòng verdict, không đọc trạng thái review |

## Check

| Triệu chứng | Chuyện gì đang xảy ra | Cần làm gì |
| --- | --- | --- |
| `UI Screenshots` thất bại khi refactor | Quy tắc không phân biệt được thay đổi nhìn thấy với thay đổi không nhìn thấy | Một maintainer thêm `no-ui-screenshots` và chạy lại check |
| Job e2e của mọi PR đều tải Chromium | Cache chỉ được lưu trên `main` | Giữ job `playwright-cache` của CI, với cùng key như PR Checks |
| `Check for mutations` thất bại trên `main` | Có thứ đã sinh ra file mà PR không commit | Chạy `pnpm build` ở local và commit phần diff |
| `Resource not accessible by integration` khi gắn label | Token của workflow ghi được issue nhưng không ghi được pull request | Thêm `pull-requests: write` vào workflow |

## Test sau merge

| Triệu chứng | Chuyện gì đang xảy ra | Cần làm gì |
| --- | --- | --- |
| Một PR đã được deploy, không có issue test | Nó không thay đổi thứ gì được deploy (chỉ docs, spec, test, tooling hoặc CI), nó mang `skip-deploy-test`, hoặc lần chạy Deploy không ship gì vì commit của nó không còn là mới nhất của `main` | Đọc các notice của lần chạy Post-merge Verify. Để vẫn test nó, chạy workflow thủ công với số PR |
| Issue test đã mở, Tester không bao giờ nhận nó | Issue không có label `openhands-test` vì thứ gì đó nó trỏ đến không khóa được, hoặc nó được mở bởi một tài khoản mà automation không tin cậy | Lần chạy Post-merge Verify thất bại và nêu tên thứ cần khóa. Khóa nó, rồi thêm label thủ công |
| Tester đã báo cáo, và bạn muốn chạy thêm lần nữa | Mỗi lần gắn label được test một lần | Gỡ và gắn lại `openhands-test` |
| Báo cáo nói "blocked" | Stage thiếu thứ gì đó mà thay đổi cần, như một tài khoản thanh toán đã kết nối | Sửa stage, rồi gắn lại label |
| Comment **E2E screenshots** bị thiếu trên một PR | PR bị khóa, và GitHub từ chối cho token của Actions comment trên một cuộc hội thoại đã khóa | Đọc danh sách trong summary của job `E2E screenshots`, hoặc mở khóa PR |
| Agent Reviewer không bao giờ đăng review, và PR bị khóa | GitHub từ chối một review gốc trên một pull request đã khóa, kể cả từ một tài khoản có quyền ghi | Mở khóa nó. Để giữ người lạ ở ngoài, hãy dùng interaction limit của repository thay vì khóa pull request |

## Deploy

| Triệu chứng | Chuyện gì đang xảy ra | Cần làm gì |
| --- | --- | --- |
| Deploy rollback với `is not authorized to perform` trên một resource mà trước đó chưa stack nào tạo | Một stack bắt đầu dùng một loại resource mà các policy của CloudFormation execution role không bao phủ | Thêm các action vào `setup-stage.sh` và chạy lại. Nó idempotent và phát hành một phiên bản mới của policy |
