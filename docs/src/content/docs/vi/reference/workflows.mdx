| Workflow | File | Trigger | Permission | Checkout |
| --- | --- | --- | --- | --- |
| PR Checks | `pr-checks.yml` | `pull_request` vào `main` | `contents: read`, cộng `pull-requests: write` cho job comment ảnh chụp màn hình | PR, trừ job comment ảnh chụp màn hình: nhánh mặc định |
| UI Screenshots | `ui-screenshots.yml` | `pull_request` vào `main`, kể cả `labeled`/`unlabeled` | `contents: read`, `pull-requests: read` | Nhánh mặc định (đọc diff từ API) |
| CI | `ci.yml` | `push` lên `main`, `workflow_dispatch` | `contents: read`, `pages: write`, `id-token: write` | `main` |
| Agent Issues | `agent-issues.yml` | `pull_request: [closed, labeled]` vào `main`, `workflow_dispatch(spec_folder)` | `contents: read`, `issues: write`, `pull-requests: write` | Merge commit |
| Archive Specs | `archive-specs.yml` | `push` lên `main` thay đổi `specs/*/tasks.md`, `workflow_dispatch` | `contents: write`, `issues: read`, `pull-requests: write` | `main` |
| Agent CI Status | `agent-ci.yml` | `workflow_run` của PR Checks, `completed` | `contents: read`, `actions: read`, `statuses: write`, `issues: write`, `pull-requests: write` | Nhánh mặc định (qua Agent Status) |
| Agent Review Status | `agent-review.yml` | `pull_request_review: submitted` | `contents: read`, `statuses: write`, `issues: write`, `pull-requests: write` | Nhánh mặc định (qua Agent Status) |
| Agent Status | `agent-status.yml` | `workflow_call` từ hai workflow trên, với Nx target cần chạy | Của workflow gọi | Nhánh mặc định |
| Cache Cleanup | `cache-cleanup.yml` | `pull_request: closed` | `actions: write` | Không gì cả (truyền số PR cho `gh`) |
| Deploy | `deploy.yml` | `workflow_run` của CI trên `main` (chỉ khi `AUTO_DEPLOY_STAGE` được đặt), `workflow_dispatch(stage)` | `contents: read`, `id-token: write` | Commit mà CI đã xác minh |
| Post-merge Verify | `post-merge-verify.yml` | `workflow_run` của Deploy, `completed`, `workflow_dispatch(pr_number)` | `contents: read`, `actions: read`, `issues: write`, `pull-requests: write` | Nhánh mặc định |

## Tên job cần yêu cầu trong branch protection

| Check | Từ |
| --- | --- |
| `Checks (lint)`, `Checks (test)`, `Checks (build)` | PR Checks |
| `Tasks format` | PR Checks |
| `Invariant coverage` | PR Checks |
| `E2E tests` | PR Checks (gom các shard) |
| `UI Screenshots` | UI Screenshots |

## Nhóm concurrency

| Workflow | Nhóm | Hủy lần đang chạy |
| --- | --- | --- |
| PR Checks | `pr-checks-<ref>` | có: một lần push mới khiến lần chạy cũ vô nghĩa |
| Agent Issues | `agent-issues-<PR number or folder>` | không |
| Archive Specs | `archive-specs` | không: mỗi lúc một lần chạy, nên hai lần chạy không bao giờ mở cùng một PR |
| Agent CI Status | `agent-ci-<head branch>` | không |
| Agent Review Status | `agent-review-<PR number>` | không |
| Deploy | `deploy-<stage>` | không |
| Post-merge Verify | `post-merge-verify` | không: mỗi lúc một lần chạy, nên hai lần deploy sát nhau không bao giờ mở hai issue cho một PR |

Các agent workflow không bao giờ hủy. Mỗi lần chạy phải tính lượt thử của nó hoặc mở issue của nó đúng
một lần, và nhóm theo từng PR nghĩa là các PR không liên quan không bao giờ phải chờ nhau.

Tất cả trong `@your-scope/tooling-agent`:

| Target | Entry point | Biến môi trường nó đọc |
| --- | --- | --- |
| `agent-issue` | `src/agent-issues/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_NAME`, `GITHUB_EVENT_PATH`, `SPEC_FOLDER`, `DRY_RUN` |
| `archive-specs` | `src/agent-issues/archive-main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_WORKSPACE`, `BASE_BRANCH`, `DRY_RUN` |
| `agent-ci-status` | `src/agent-ci/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_PATH`, `DRY_RUN` |
| `agent-review-status` | `src/agent-review/main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_EVENT_PATH`, `AGENT_APP_LOGIN`, `DRY_RUN` |
| `validate-tasks` | `src/agent-issues/validate-main.ts` | `GITHUB_WORKSPACE`, `GITHUB_ACTIONS` (cho annotation) |

| `screenshots-comment` | `src/ui-screenshots/comment-main.ts` | `GH_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_STEP_SUMMARY`, `PR`, `SHA`, `RUN_URL`, `SCREENSHOTS_DIR` |

## Biến repository

| Biến | Đọc bởi | Mặc định |
| --- | --- | --- |
| `AUTO_DEPLOY_STAGE` | Deploy | Không đặt: Deploy chỉ chạy bằng tay |
| `TEST_STAGE` | Post-merge Verify | `AUTO_DEPLOY_STAGE` |
| `AWS_REGION`, `AWS_DEPLOY_ROLE_ARN`, `AWS_EXECUTION_ROLE_ARN` | Deploy, trên GitHub environment của mỗi stage | Không có. Deploy dừng lại và nêu tên thứ còn thiếu |
| `AWS_DOCKER_LOGIN_ROLE_ARN` | `init-monorepo`, cho các lần pull từ Amazon ECR Public | Không đặt: pull ẩn danh |
