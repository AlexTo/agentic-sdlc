Một [bản fork của repository này](../../guides/fork-this-repo/) có mọi thứ mà thiết lập của Discava
giữ trong repository. Các bước này bổ sung phần nằm ngoài nó: các cài đặt GitHub của bạn, một GitHub
App để agent hoạt động dưới danh nghĩa của nó, và một bản cài OpenHands trỏ vào bản fork. Sau đó bạn
viết một spec cho ứng dụng ghi chú và xem nó đi từ spec PR đến các agent PR đã merge.

**Thời gian:** khoảng một giờ, phần lớn là chờ lần chạy agent đầu tiên.

## Bạn cần gì

Trên macOS hoặc Linux (trên Windows, hãy dùng WSL):

| Cần | Vì sao |
| --- | --- |
| Một tài khoản GitHub | Để fork, viết spec và review |
| GitHub CLI (`gh`), đã đăng nhập | Script thiết lập và các agent dùng nó |
| Node.js 24 và pnpm | Để chạy repository và Agent Canvas |
| `uv` | Agent Canvas khởi động backend của nó bằng `uvx` |
| Một coding agent, đã cài và đăng nhập | Nó viết spec bằng Speckit, và làm công việc của các agent bên trong OpenHands. Discava dùng Claude Code |
| Docker (tùy chọn) | Chỉ để chạy ứng dụng ghi chú và e2e test của nó trên máy bạn. CI chạy chúng cho các agent |

<Aside type="note">
Agent Canvas chạy trên máy của chính bạn và poll GitHub, nên nó không cần địa chỉ công khai hay
webhook. Agent chỉ làm việc khi nó đang chạy.
</Aside>

## Các bước

| # | Bước | Bạn làm | Kết quả |
| --- | --- | --- | --- |
| 1 | [Fork repository](../fork/) | Ba lệnh | Bản sao của riêng bạn, đã clone |
| 2 | [Cấu hình repository](../github-repository/) | Tạo một GitHub App từ một form đã điền sẵn, chạy một script | GitHub App của agent trên bản fork của bạn, các label, một `main` được bảo vệ, comment giới hạn cho collaborator |
| 3 | [Cài OpenHands](../openhands/) | Hai lệnh, hai profile trong giao diện web | Agent Canvas chạy dưới danh nghĩa app của bạn, với một profile `developer` và một profile `reviewer` |
| 4 | [Tạo hai automation](../automations/) | Hai form trong giao diện web, một prompt dán vào | Các agent Developer và Reviewer triển khai và review trong bản fork của bạn |
| 5 | [Chạy tính năng đầu tiên](../first-feature/) | Viết một spec, review các pull request | Một spec cho ứng dụng ghi chú, được agent đưa đến code đã merge |
