Một [bản fork của repository này](../../guides/fork-this-repo/) có mọi thứ mà thiết lập của Discava
giữ trong repository. Các bước này bổ sung phần nằm ngoài nó: các cài đặt GitHub của bạn, và một bản
cài OpenHands trỏ vào bản fork. Sau đó bạn viết một spec cho ứng dụng ghi chú và xem nó đi từ spec PR
đến các agent PR đã merge.

**Thời gian:** khoảng một giờ, phần lớn là chờ lần chạy agent đầu tiên.

## Bạn cần gì

| Cần | Vì sao |
| --- | --- |
| Một tài khoản GitHub | Để fork, viết spec và review |
| Một tài khoản GitHub thứ hai cho agent | Nó sở hữu token mà agent dùng, nên PR và comment của agent là của chính chúng và bạn có thể duyệt chúng. Tài khoản của Discava là `discava-bot` |
| Node.js 24 và pnpm | Để chạy repository và Agent Canvas |
| `uv` | Agent Canvas khởi động backend của nó bằng `uvx` |
| Docker | Chỉ để chạy ứng dụng ghi chú và e2e test của nó ở local. CI chạy chúng cho agent |
| GitHub CLI (`gh`), đã đăng nhập | Hầu hết các bước dùng nó |
| Một coding agent, đã cài và đăng nhập | Viết spec bằng Speckit, và chạy bên trong OpenHands. Discava dùng Claude Code |

<Aside type="note">
Agent Canvas chạy trên máy của chính bạn và poll GitHub, nên nó không cần địa chỉ công khai hay
webhook. Agent chỉ làm việc khi nó đang chạy.
</Aside>
