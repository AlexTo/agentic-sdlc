Repository này là một bản sao hoạt động của thiết lập agentic của Discava, bao quanh một ứng dụng ghi
chú nhỏ. **Fork nó và bạn có cùng thiết lập mà Discava chạy**: template Speckit và constitution, issue
template, PR check, ba agent workflow và phần glue có unit test đứng sau chúng.

Thứ mà bản fork không có là phần nằm ngoài repository: các cài đặt GitHub của bạn, và một bản cài
OpenHands trỏ vào bản fork. Các bước này bổ sung những thứ đó. Sau đó bạn viết một spec cho ứng dụng
ghi chú và xem nó đi qua đúng quy trình mà Discava dùng, từ spec PR đến các agent PR đã merge.

**Thời gian:** khoảng một giờ, phần lớn là chờ lần chạy agent đầu tiên.

## Bạn cần gì

| Cần | Vì sao |
| --- | --- |
| Một tài khoản GitHub | Để fork, và để sở hữu token mà agent dùng |
| Node.js 24 và pnpm | Để chạy repository và Agent Canvas |
| `uv` | Agent Canvas khởi động backend của nó bằng `uvx` |
| Docker | Chỉ để chạy ứng dụng ghi chú và e2e test của nó ở local. CI chạy chúng cho agent |
| GitHub CLI (`gh`), đã đăng nhập | Hầu hết các bước dùng nó |
| Một coding agent, đã cài và đăng nhập | Viết spec bằng Speckit, và chạy bên trong OpenHands. Discava dùng Claude Code |

<Aside type="note">
Agent Canvas chạy trên máy của chính bạn và poll GitHub, nên nó không cần địa chỉ công khai hay
webhook. Nhưng nó cần đang chạy thì agent mới làm việc được. Hãy để nó chạy trong khi bạn thử quy trình.
</Aside>
