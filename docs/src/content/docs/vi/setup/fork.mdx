**Kết quả:** bản fork của riêng bạn, đã bật Issues và Actions, đã clone về máy, với các check đều
pass.

<Steps>

1. **Fork và clone.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Đặt bản fork làm mặc định cho `gh`.** Nếu không, các lệnh `gh` sẽ nhắm vào repository gốc,
   không phải của bạn.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Bật Issues.** GitHub tắt chúng cho bản fork, mà toàn bộ quy trình chạy trên issue. Trong bản
   fork, mở **Settings → General → Features** và chọn **Issues**.

4. **Bật Actions.** Mở tab **Actions** của bản fork và bấm **I understand my workflows, go
   ahead and enable them**. GitHub không chạy workflow trong bản fork cho đến khi bạn làm vậy.

5. **Cài đặt và chạy các check ở local**, đúng những check mà CI chạy:

   ```bash
   pnpm install
   pnpm nx run-many --target lint --all
   pnpm nx run-many --target test --all
   pnpm nx run-many --target build --all
   ```

   Để chạy ứng dụng ghi chú (cần Docker): `pnpm dev`, rồi mở URL mà website in ra.

</Steps>

## Kiểm tra kết quả

Bản fork của bạn hiện một tab **Issues**, và tab **Actions** của nó liệt kê các workflow. Ở local,
ba lệnh `nx run-many` đều pass.

<Aside type="note">
Có hai thứ hoạt động khác trong bản fork, và không cái nào chặn quy trình. Không có secret
`CODECOV_TOKEN`, bước upload coverage log một lỗi rồi tiếp tục. Job **Deploy Docs** trong CI thất
bại cho đến khi bạn bật GitHub Pages (**Settings → Pages → Source: GitHub Actions**), hoặc bạn có
thể bỏ qua nó.
</Aside>
