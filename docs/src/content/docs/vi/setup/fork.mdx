**Kết quả:** bản fork của riêng bạn, đã clone về máy, sẵn sàng cho script thiết lập.

<Steps>

1. **Fork và clone.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Đặt bản fork làm mặc định cho `gh`.** Nếu không, các lệnh `gh`, và các pull request bạn mở
   bằng nó, sẽ nhắm vào repository gốc, không phải của bạn.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Cài các dependency.**

   ```bash
   pnpm install
   ```

   Lệnh này cũng cài các git hook mà bạn sẽ gặp khi commit spec đầu tiên: Conventional Commits trên
   mọi commit message, và quét secret cùng Biome trước mọi commit.

</Steps>

## Kiểm tra kết quả

```bash
gh repo set-default --view
```

in ra `<you>/agentic-sdlc`.

GitHub tắt Issues và Actions trong bản fork. Script ở bước tiếp theo bật chúng lại.

<Aside type="tip" title="Tùy chọn: xem nó chạy">
Để chạy những gì CI chạy (lint, test và build): `pnpm build`. Để chạy ứng dụng ghi chú (cần
Docker): `pnpm dev`, rồi mở URL mà website in ra. Cả hai đều không cần cho việc thiết lập: CI chạy
các check trên mọi pull request.
</Aside>

<Aside type="note">
Không có secret `CODECOV_TOKEN`, bước upload coverage của CI log một lỗi rồi tiếp tục. Thêm secret,
hoặc xóa bước đó, nếu bạn muốn nó im lặng.
</Aside>
