**Kết quả:** bản fork của riêng bạn, đã clone về máy, với các check đều pass.

<Steps>

1. **Fork và clone.**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **Đặt bản fork làm mặc định cho `gh`.** Nếu không, các lệnh `gh` sẽ nhắm vào repository gốc,
   không phải của bạn.

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **Cài đặt và chạy các check ở local**, đúng những check mà CI chạy:

   ```bash
   pnpm install
   pnpm nx run-many --target lint --all
   pnpm nx run-many --target test --all
   pnpm nx run-many --target build --all
   ```

   `pnpm install` cũng cài các git hook: Conventional Commits trên mọi commit message, quét secret
   và Biome trước mọi commit, và kiểm tra bản đồ invariant trước mọi push. Để chạy ứng dụng ghi chú
   (cần Docker): `pnpm dev`, rồi mở URL mà website in ra.

</Steps>

## Kiểm tra kết quả

Ba lệnh `nx run-many` đều pass, và một commit có message không phải Conventional Commit bị từ
chối:

```bash
git commit --allow-empty -m "not conventional"
```

```text
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

GitHub tắt Issues và Actions trong bản fork. Script ở bước tiếp theo bật chúng lại.

<Aside type="note">
Không có secret `CODECOV_TOKEN`, bước upload coverage của CI log một lỗi rồi tiếp tục. Thêm secret,
hoặc xóa bước đó, nếu bạn muốn nó im lặng.
</Aside>
