**Bạn đang ở:** ⚙️ automation, không người giám sát. **Output:** một PR xanh với một review duyệt từ agent.

Mỗi lần push lên PR của agent đều chạy các cổng. Thất bại quay về agent, không bao giờ về bạn.

## Các cổng

| Cổng | Bắt được gì trong trường hợp tag |
| --- | --- |
| Lint, typecheck, build | Một kiểu API không còn khớp với entity |
| Unit test | Tag thứ sáu được chấp nhận, hoặc `Work` và `work` được lưu thành hai tag |
| Invariant | Bất kỳ ghi chú nào trong bảng có hơn năm tag, sau mỗi e2e test |
| E2E test | Ô nhập tag không lưu, hoặc bộ lọc hiện sai ghi chú |
| Test đồng thời | Hai lần thêm đồng thời ghi đè lên nhau và một tag bị mất |
| Ảnh chụp màn hình | UI mới chưa từng được nhìn qua: check `UI Screenshots` thất bại |
| Kiểm tra định dạng tasks | Một `tasks.md` sai định dạng sẽ làm chuỗi đứng lại |

## Khi một cổng thất bại

1. Workflow **Agent CI Status** đánh dấu head commit của PR là thất bại.
2. Agent sửa lại *chính* PR đó trong cuộc hội thoại ban đầu của nó, dựa trên output thất bại.
3. CI chạy lại.

Một ví dụ: test đồng thời thất bại vì việc thêm tag đọc ghi chú, nối thêm trong bộ nhớ rồi ghi lại,
nên hai request tranh nhau. Agent đổi nó thành một thao tác nối nguyên tử với điều kiện trên số
lượng, và test chuyển xanh. Bạn không hề thấy nó.

## Agent review

Khi CI xanh, một agent OpenHands thứ hai, agent Reviewer, review PR như một người sẽ làm: tính đúng đắn, edge case
bị sót, các quy tắc từ spec mà không test nào bao phủ. Nó hoặc duyệt, hoặc yêu cầu thay đổi, điều
này gửi agent Developer quay lại theo cùng cách như một lần CI đỏ.

## Giới hạn

Mỗi vòng bị giới hạn ở **năm** lượt thử cho mỗi PR, đếm bằng label: `ci-fix-1` đến `ci-fix-5` cho
CI, `review-fix-1` đến `review-fix-5` cho review. Sau lượt thứ năm, workflow comment, thêm
`ci-fix-exhausted` hoặc `review-fix-exhausted`, và dừng.

<Aside type="caution">
Một vòng bị cạn là lần duy nhất bạn bị kéo vào sớm.
[Cổng người duyệt](../../concepts/human-gates/#khi-nào-bạn-bị-kéo-vào-sớm) nói cần làm gì.
</Aside>
