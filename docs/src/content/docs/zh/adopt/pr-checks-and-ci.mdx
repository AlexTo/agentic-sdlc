**完成后你将拥有：** 一个失败结果会进入 CI 循环的 **PR Checks** workflow、一项 **UI Screenshots** 检查，以及 `main` 上的 **CI**。

<Steps>

1. 从这个仓库的 `.github/workflows/` **复制四个 workflow**：

   | 文件 | 作用 |
   | --- | --- |
   | `pr-checks.yml` | 对 PR 影响到的部分运行 lint、test 和 build；`Tasks format`；`Invariant coverage`；分片运行的 e2e，汇总成一项 `E2E tests` 检查；`E2E screenshots` 评论 |
   | `ui-screenshots.yml` | 截图规则，作为一个独立的 workflow，这样添加或移除 `no-ui-screenshots` 标签时只会重新运行这一项检查。Discava 则把它作为 PR Checks 中的一个 job 来运行。两种方式都可以 |
   | `ci.yml` | 每次推送到 `main` 时运行同样的检查、Trivy、Playwright 缓存，以及本文档站点的部署 |
   | `cache-cleanup.yml` | PR 关闭时删除该 PR 的缓存 |

   保持 `pr-checks.yml` 的 `name: PR Checks` 一字不差：Agent CI Status 监听的就是这个名称的 workflow。

2. **让它们指向你的项目。** 在复制来的文件中搜索 `@agentic-sdlc/` 并修改 scope。然后，在 `pr-checks.yml` 中：

   | Job | 修改 |
   | --- | --- |
   | `invariant-coverage` | 可能写入你的表的代码所在的 `paths`，与第 5 步中的 `WRITER_PACKAGES` 相同。如果你暂时不检查不变式，就删掉这个 job |
   | `e2e` | `matrix.shard` 中的分片数，按你的测试套件设置。一个分片在运行第一个测试之前大约要花两分钟，所以当每个分片的测试大约也只需要这么久时，就不要再加分片了 |
   | `e2e-screenshots` | 无需修改，只要完成了[第 8 步](../local-stack-and-e2e/) |

   在 `ci.yml` 中，删除 `deploy_docs` job 及其 `pages: write` 权限，除非你要从 `docs/` 发布一个文档站点。

3. **保留让智能体保持快速的部分。** `ci.yml` 中的 `Check for mutations` 步骤（构建之后执行 `git diff
   --exit-code`）能发现智能体忘记提交的生成文件。`playwright-cache` job 从 `main` 保存 Chromium，因为 PR 的运行只能恢复在那里保存的缓存。`build` job 从 `main` 保存 Nx 的任务缓存，所以 PR 的第一次运行会回放 `main` 已经构建过的内容，智能体在每一轮修复中都能少等一些。PR Checks 中的每个 `checks` 分支也以同样的方式保留自己的缓存，只有 `lint` 例外，它只恢复缓存。`init-monorepo` 把缓存上限设为 1 GB，Cache Cleanup 会释放已关闭 PR 在仓库 10 GB 额度中所占的部分。这为 Discava 节省了什么，见[保持快速](../../discava/pr-checks/#保持快速)。

</Steps>

每个 action 都固定到一个 commit SHA，你在第 1 步中复制的 `dependabot.yml` 会让这些固定版本保持最新。

## 检查是否成功

开一个用完即弃的 PR，弄坏 `tasks.md` 中的某一行，例如给一个任务加缩进。**Tasks format** 检查会失败，并在那一行上给出 annotation：

```text
A task must be written "- [ ] T<3 digits> <description>", starting in the first column
```

再开一个修改了 UI 文件但没有改动任何场景的 PR。**UI Screenshots** 会失败：

```text
This pull request changes UI source (…) but no e2e scenario gained a `screenshot(page, 'name')` call.
```

<Aside type="note">
复制来的文件中的 `codecov/codecov-action` 需要一个 `CODECOV_TOKEN` secret。如果你不使用 Codecov，就删掉这一步。
</Aside>
