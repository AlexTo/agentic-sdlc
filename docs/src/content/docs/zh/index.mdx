<CardGrid>
  <Card title="一个值得信任的环境" icon="approve-check">
    规则、测试和检查层层叠加，让错误暴露出来并回到智能体那里，而不是落到你身上。
  </Card>
  <Card title="编写 spec" icon="pencil">
    每个功能都从一份经过评审的 spec、计划和任务列表开始。智能体依据它们来构建，而不是依据一段聊天。
  </Card>
  <Card title="其余的交给智能体" icon="rocket">
    合并后的 spec 会为每个阶段开一个 issue。智能体自己开 PR，并自行修复红色的 CI 或评审意见，每个循环最多五次。
  </Card>
  <Card title="由你掌舵" icon="information">
    人负责批准 spec，并在合并前拥有最终决定权。中间的一切都自动运行。
  </Card>
</CardGrid>
