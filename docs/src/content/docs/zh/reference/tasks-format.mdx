## 格式

```markdown
# Tasks: Course ratings and reviews

Free text, legends and notes anywhere. Fenced code blocks are ignored.

## Phase 1: Setup
- [x] T001 Create the review entity
- [ ] T002 [P] Add the rating summary entity

## Phase 2: Foundational
- [ ] T003 Shared review writer in core-table helpers

## Phase 3: User Story 1 - Leave a rating (Priority: P1) 🎯 MVP
### Tests for User Story 1
- [ ] T004 [P] [US1] Unit tests for rating rules
### Implementation for User Story 1
- [ ] T005 [US1] review.upsert procedure
- [ ] T006 (human) Check the layout on a phone-width window

## Phase 4: User Story 2 - Instructor responds (Priority: P2)
- [ ] T007 [US2] review.respond procedure
- [ ] T037 [US2] Notify the student (added later: next unused id)
```

| 元素 | 模式 | 说明 |
| --- | --- | --- |
| 阶段 | `^## Phase (\d+): (.+)$` | 编号自上而下递增。每个阶段至少有一个任务 |
| 用户故事阶段 | 标题以 `User Story` 开头 | 至少要有一个 |
| 任务 | `^- \[([ xX])\] (T\d{3})\b` | 位于第一列，在某个阶段之下。ID 唯一，从不重新编号 |
| 已完成 | `[x]` 或 `[X]` | 原地勾选，从不删除 |
| 人工任务 | 行内任意位置有 `(human)`，加粗与否均可 | 智能体会跳过，判断一个组是否完成时也不计入 |
| 子标题 | `### …` | 允许，会被忽略 |

## 阶段如何变成 issue

1. **第 0 组**包含从开头到第一个 `User Story` 阶段（含）的所有阶段。Setup、基础部分和 MVP 故事作为一个 PR 一起交付，标题带有 ` (with setup and foundations)`。
2. **之后的每个阶段**各自成为一个组，各有自己的 issue。
3. **下一组**是第一个含有未勾选、且不是 **(human)** 的任务的组。
4. 如果一个组的 issue 已经存在，但其中的智能体任务没有全部勾选，这个组就是**停滞**的。不会开新的 issue，已合并的 PR 会收到一条列出未勾选 ID 的评论。

issue 标题为 `feat(<feature>): <last phase's title, shortened>`。`<feature>` 是去掉时间戳的文件夹名。缩短后的标题去掉 `User Story <n> - ` 前缀和 `(Priority: Pn)` 后缀。标题以小写字母开头，最多 100 个字符。

## 校验器消息

| 消息 | 修复方法 |
| --- | --- |
| `A phase heading must be written "## Phase <number>: <title>"` | 某个标题提到了 “Phase”，但格式不对，例如 `### Phase 2` 或 `## Phase 2 - Setup` |
| `A task must be written "- [ ] T<3 digits> <description>", starting in the first column` | 任务有缩进、写成 `* [ ]`、`- []`，或 ID 形如 `T12` |
| `Phase <n> has no tasks` | 添加一个任务，或删除该阶段 |
| `Phase <n> comes after phase <m>; phase numbers must increase down the file` | 重新给阶段编号（不是任务） |
| `T0xx is above the first phase heading, so it belongs to no phase` | 把它移到某个阶段下 |
| `T0xx is used more than once` | 给后出现的那个分配下一个未使用的 ID |
| `No phase headings found; …` | 文件完全不符合格式 |
| `No phase is titled "User Story <n> - ..."; …` | 至少把一个阶段命名为用户故事 |

在本地运行：

```bash
pnpm nx run @your-scope/tooling-agent:validate-tasks
```
