**完成后你将拥有：** 你自己的 fork，已克隆到本地，可以运行设置脚本了。

<Steps>

1. **Fork 并克隆。**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **把你的 fork 设为 `gh` 的默认仓库。** 否则 `gh` 命令，以及你用它开的 pull request，都会作用于原仓库，而不是你的仓库。

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **安装依赖。**

   ```bash
   pnpm install
   ```

   这还会安装 git hooks，你在提交第一份 spec 时会遇到它们：每条 commit 信息都要符合 Conventional Commits，每次提交前扫描 secret 并运行 Biome。

</Steps>

## 检查是否成功

```bash
gh repo set-default --view
```

会打印 `<you>/agentic-sdlc`。

GitHub 在 fork 中关闭了 Issues 和 Actions。下一步中的脚本会把它们重新打开。

<Aside type="tip" title="可选：看它运行起来">
运行 CI 所运行的内容（lint、测试和构建）：`pnpm build`。运行笔记应用（需要 Docker）：`pnpm dev`，然后打开网站打印出的 URL。这两者都不是设置所必需的：CI 会在每个 pull request 上运行这些检查。
</Aside>

<Aside type="note">
没有 `CODECOV_TOKEN` secret 时，CI 的覆盖率上传步骤会记录一个错误然后继续。如果你想让它安静下来，添加这个 secret，或者删除这一步。
</Aside>
