**完成后你将拥有：** 你自己的 fork，已克隆到本地，并且检查全部通过。

<Steps>

1. **Fork 并克隆。**

   ```bash
   gh repo fork AlexTo/agentic-sdlc --clone
   cd agentic-sdlc
   ```

2. **把你的 fork 设为 `gh` 的默认仓库。** 否则 `gh` 命令会作用于原仓库，而不是你的仓库。

   ```bash
   gh repo set-default <you>/agentic-sdlc
   ```

3. **在本地安装并运行检查**，与 CI 运行的检查相同：

   ```bash
   pnpm install
   pnpm nx run-many --target lint --all
   pnpm nx run-many --target test --all
   pnpm nx run-many --target build --all
   ```

   `pnpm install` 还会安装 git hooks：每条 commit 信息都要符合 Conventional Commits，每次提交前扫描 secret 并运行 Biome，每次推送前检查不变式映射。运行笔记应用（需要 Docker）：`pnpm dev`，然后打开网站打印出的 URL。

</Steps>

## 检查是否成功

三条 `nx run-many` 命令都通过，并且 commit 信息不符合 Conventional Commits 的提交会被拒绝：

```bash
git commit --allow-empty -m "not conventional"
```

```text
✖   subject may not be empty [subject-empty]
✖   type may not be empty [type-empty]
```

GitHub 在 fork 中关闭了 Issues 和 Actions。下一步中的脚本会把它们重新打开。

<Aside type="note">
没有 `CODECOV_TOKEN` secret 时，CI 的覆盖率上传步骤会记录一个错误然后继续。如果你想让它安静下来，添加这个 secret，或者删除这一步。
</Aside>
